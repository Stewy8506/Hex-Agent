# Plan 11.02: Hermes-Style Learning Loop & Skill Synthesizer with NVIDIA SkillSpector

<objective>
Implement the Hermes-style learning loop and self-synthesizing skills engine (`src/harness_core/skill_synthesizer.py`) and wire skill commands into the HEX CLI (`src/harness_core/cli.py`). Build `SkillSynthesizer` to inspect completed tasks, distill reusable engineering workflows into structured `SKILL.md` bundles, and enforce a **Mandatory NVIDIA SkillSpector Gate** (`SkillSecurityScanner` from `src/harness_core/skillspector.py`) before writing to disk. Clean skills are registered in `skills/custom/<name>/SKILL.md` and indexed in the ledger for future prompt grounding; suspicious or injection-poisoned skills are safely quarantined in `.hex/quarantine/`. Wire `hex skill synthesize`, `hex skill list`, and `hex skill scan` subcommands into `src/harness_core/cli.py`. Author a comprehensive test suite in `tests/test_skill_synthesis.py`.

Purpose: Deliver the self-synthesizing skill learning loop of Pillar 5 (Autonomous Background Automations & Hermes-Style Self-Synthesizing Skills), enabling HEX to compound engineering knowledge autonomously while maintaining strict supply-chain malware defense.
Output: `src/harness_core/skill_synthesizer.py`, updated `src/harness_core/cli.py`, and `tests/test_skill_synthesis.py`.
</objective>

  <name>Implement Hermes-Style Skill Synthesizer with Task Trace Pattern Extraction & Mandatory NVIDIA SkillSpector Gate</name>
  <files>src/harness_core/skill_synthesizer.py</files>
  <action>
    Create `src/harness_core/skill_synthesizer.py`:
    1. Dataclass `SynthesizedSkill`:
       - `name: str`
       - `purpose: str`
       - `description: str`
       - `risk_class: str = "R1"`
       - `allowed_tools: list[str] = field(default_factory=list)`
       - `trigger: str = ""`
       - `content: str = ""`
       - `status: str = "candidate"` ("active", "quarantined", "candidate")
       - `scan_report: dict[str, Any] = field(default_factory=dict)`
       - `disk_path: str | None = None`
       - `quarantine_reason: str | None = None`
       - `to_dict() -> dict[str, Any]`.
    2. Engine Class `SkillSynthesizer`:
       - `__init__(self, ledger: LedgerStore, scanner: SkillSecurityScanner | None = None, custom_skills_dir: Path | str | None = None, quarantine_dir: Path | str | None = None)`:
         - Default `custom_skills_dir`: project `skills/custom` (fallback `~/.hex/skills/custom`).
         - Default `quarantine_dir`: project `.hex/quarantine` (fallback `~/.hex/quarantine`).
         - Uses provided `scanner` or instantiates `SkillSecurityScanner(ledger)`.
       - `extract_task_context(self, task_id: str) -> dict[str, Any]`:
         - Retrieves task record via `ledger.get_task(task_id)`. Verifies task status is `COMPLETED` (raises `ValueError` if task is not found or not completed).
         - Retrieves proof bundle via `ledger.get_proof_bundle(task_id)`.
         - Retrieves tool invocations via `ledger.get_call_journal(task_id)`.
         - Extracts:
           - Goal and project ID.
           - Tools called (deduplicated list of tool names).
           - Files modified or inspected.
           - AST impact summary and test results from proof bundle.
       - `generate_skill_markdown(self, name: str, goal: str, tools_used: list[str], files_modified: list[str], verification_passed: bool, code_summary: str = "") -> str`:
         - Normalizes skill name to snake_case identifier.
         - Determines highest risk class based on tools used (`R0` if read-only, `R1` if inspection/tests, `R2` if write_file, `R3` if git_commit/push).
         - Generates YAML frontmatter:
           ```yaml
           ---
           name: {name}
           purpose: {distilled purpose}
           description: {distilled description}
           risk_class: {risk_class}
           allowed_tools: [{tools_used}]
           trigger: {name}
           ---
           ```
         - Generates Markdown body sections:
           - `# {name.replace('_', ' ').title()}`
           - `## Overview & Problem Pattern`
           - `## Required Toolchain`
           - `## Step-by-Step Execution Workflow`
           - `## Verification Standards`
       - `synthesize_skill(self, task_id: str, skill_name: str | None = None, dry_run: bool = False) -> SynthesizedSkill`:
         - Extracts task context via `extract_task_context(task_id)`.
         - Generates normalized skill name (from `skill_name` or slugified task goal).
         - Generates full `SKILL.md` text.
         - **Mandatory NVIDIA SkillSpector Gate**:
           - Writes temporary candidate bundle or invokes `self.scanner` inspection directly.
           - Scans the synthesized content for:
             - Prompt injection patterns (e.g. "ignore previous instructions", hidden markdown tags).
             - Data exfiltration patterns and reverse shells (`nc -e`, `curl ... | bash`).
             - OSV vulnerable packages or harmful constructs.
             - Semantic alignment (checks that declared purpose and risk match instructions).
           - Evaluates `gate_decision`:
             - If `gate_decision == "ALLOW"` and `max_score < 25`:
               - Status is `"active"`.
               - If not `dry_run`:
                 - Writes to `custom_skills_dir / skill_name / SKILL.md`.
                 - Registers in `ledger` via `self.scanner.scan_and_register_skill(bundle_dir)`.
             - Else (`gate_decision in ("QUARANTINE", "REQUIRE_APPROVAL")` or `max_score >= 25`):
               - Status is `"quarantined"`.
               - `quarantine_reason`: list of triggered rules or scan explanation.
               - If not `dry_run`:
                 - Writes to `quarantine_dir / skill_name / SKILL.md`.
                 - Writes `quarantine_dir / skill_name / audit.json` containing full scan details.
           - Returns `SynthesizedSkill` object.
       - `list_skills(self) -> dict[str, list[dict[str, Any]]]`:
         - Enumerates built-in skills (`skills/*`), custom skills (`skills/custom/*`), and quarantined skills (`.hex/quarantine/*`).
         - Returns dictionary with categories: `"built_in"`, `"custom"`, and `"quarantined"`, along with status and risk badges.

    AVOID: Allowing any synthesized skill to bypass the NVIDIA SkillSpector scanner. Even locally synthesized skills must undergo 100% of the static, OSV, and semantic checks before disk persistence.
  </action>

  </verify>
