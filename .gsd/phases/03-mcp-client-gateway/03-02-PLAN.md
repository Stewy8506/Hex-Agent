  <name>Extend SkillSecurityScanner with MCP manifest scanning and SHA-256 manifest pinning</name>
  <files>src/harness_core/skillspector.py</files>
  <action>
    Enhance `SkillSecurityScanner` in `src/harness_core/skillspector.py` to pre-validate external MCP tool manifests:
    1. Implement `compute_mcp_manifest_sha256(manifest_data: dict[str, Any]) -> str`:
       - Deterministically hashes canonical JSON representation of server configuration and tool schemas.
    2. Implement `scan_mcp_manifest(self, server_id: str, manifest: dict[str, Any], tools: list[dict[str, Any]] | list[Any]) -> dict[str, Any]`:
       - Computes `manifest_sha256`.
       - Extracts text from server configuration (command, args, URL, environment variables) and all tools (names, descriptions, input schemas, parameter descriptions, parameter names).
       - Scans text corpus against compiled security rules (`self.rules`), checking for:
         - Hidden Markdown / HTML prompt injections (e.g. `<!-- IGNORE ALL PREVIOUS INSTRUCTIONS -->`, `<system>`, `[INSTRUCTION]`).
         - Invisible Unicode steganography / zero-width characters / bidi overrides.
         - Shell exfiltration payloads (`curl ... | sh`, `wget`, `bash -c`, `base64 -d`).
         - Rogue agent and tool misuse patterns.
         - Malicious default arguments or schema descriptions prompting secret leakage.
       - Evaluates semantic alignment:
         - Checks if tools expose destructive capabilities (e.g. `delete_system`, `format_disk`) while the server claims read-only utility.
       - Computes `max_score`, `severity`, and `gate_decision`:
         - `max_score >= 60`: `QUARANTINE` (severity: `"critical"` or `"high"`, status: `"quarantined"`).
         - `25 <= max_score < 60`: `REQUIRE_APPROVAL` (severity: `"medium"`, status: `"candidate"`).
         - `max_score < 25`: `ALLOW` (severity: `"low"` or `"info"`, status: `"active"`).
       - Creates `SkillScanReport` and persists audit record in `skill_scans` table (and `skills` table with `skill_id = f"mcp_{server_id}"`, `bundle_sha256 = manifest_sha256`).
       - Returns dictionary:
         `{"server_id": server_id, "manifest_sha256": manifest_sha256, "status": status, "gate_decision": gate_decision, "scan": report.to_dict()}`.
    3. Implement `verify_mcp_manifest_integrity(self, server_id: str, manifest_sha256: str) -> bool`:
       - Queries the latest scan record for `mcp_{server_id}` from ledger.
       - Validates that the recorded `bundle_sha256` matches `manifest_sha256` and status is `"active"`.
       - Returns `True` if valid, `False` if tampered, missing, or quarantined.
    AVOID: Allowing uninspected tool descriptions into the prompt context without recording a passing scan.
  </action>

  <done>SkillSecurityScanner can inspect external MCP manifests, detect prompt injections, compute pinned SHA-256, and persist audit scans.</done>

<task type="auto">
  <name>Integrate dynamic MCP tool registration and 0ms call journaling into ToolGateway</name>
  <files>src/harness_core/gateway.py</files>
  <action>
    Enhance `ToolGateway` in `src/harness_core/gateway.py` to register and mediate MCP tools:
    1. Import `MCPClientAdapter`, `MCPToolDefinition` from `.mcp_client` and `SkillSecurityScanner` from `.skillspector`.
    2. Add `self.mcp_servers: dict[str, dict[str, Any]] = {}` in `ToolGateway.__init__`.
    3. Implement `register_mcp_server(self, adapter: MCPClientAdapter, scanner: SkillSecurityScanner | None = None, enforce_scan: bool = True) -> list[str]`:
       - Discovers tools by calling `adapter.discover_tools()`.
       - Retrieves manifest data via `adapter.get_manifest_data()`.
       - If `enforce_scan`:
         - Uses provided `scanner` or creates `SkillSecurityScanner(self.ledger)`.
         - Executes `scan_res = scanner.scan_mcp_manifest(adapter.server_id, manifest_data, tools)`.
         - If `scan_res["gate_decision"] != "ALLOW"` or `scan_res["status"] == "quarantined"`:
           - Raises `PolicyBlockedError(f"MCP server '{adapter.server_id}' rejected by SkillSpector: {scan_res['scan']['matched_rules']}")`.
       - Pins manifest SHA-256:
         `self.mcp_servers[adapter.server_id] = {"adapter": adapter, "manifest_sha256": manifest_data.get("manifest_sha256")}`.
       - For each tool in discovered tools:
         - Creates namespaced `tool_id = f"{adapter.server_id}__{tool.name}"` (and registers direct alias `tool.name` if unique and non-conflicting with built-ins).
         - Constructs handler closure:
           ```python
           def _make_handler(client: MCPClientAdapter, target_tool: str):
               def handler(ws_path: Path, args: dict[str, Any]) -> dict[str, Any]:
                   return client.call_tool(target_tool, args)
               return handler
           ```
         - Builds `ToolSpec(tool_id=tool_id, description=tool.description, risk_class=tool.risk_class, handler=_make_handler(adapter, tool.name))`.
         - Registers into `self.tools[tool_id]`.
       - Returns list of registered tool IDs.
    4. Ensure seamless mediation through existing `ToolGateway.invoke`:
       - Policy check (`evaluate_policy`) applies to MCP tools: Fast-path prohibits R2..R4; R3 requires human approval record; R4 is denied.
       - Secret redaction runs on arguments before journaling.
       - Prior call lookup (`self.ledger.find_sealed_tool_call`) checks for existing sealed call matching `(task_id, step_id, tool_id, args_hash)`.
       - If found: returns memoized result in ~0 ms with `_replayed: True`, skipping `call_tool`.
       - Pre-execution journal entry (`begin_tool_call`) is created with monotonic sequence and canonical args hash.
       - MCP tool execution runs inside try/except block.
       - On exception: records `seal_tool_call` with `status="FAILED"`.
       - On success: redacts result secrets and records `seal_tool_call` with `status="SEALED"`, duration_ms, and result SHA-256.
    AVOID: Allowing an external MCP call to execute without first recording a PENDING entry in the call journal.
  </action>
  <verify>python3 -c "from harness_core.gateway import ToolGateway; print('register_mcp_server available:', hasattr(ToolGateway, 'register_mcp_server'))"</verify>
  <done>ToolGateway registers external MCP servers with SkillSpector pre-validation, policy mediation, and 0ms call journal replay.</done>
