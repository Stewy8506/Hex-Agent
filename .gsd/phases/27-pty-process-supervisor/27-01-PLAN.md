# Plan 27.01: PTY ProcessRegistry & Circular Ring Buffer Core

## Objective
Implement an asynchronous pseudo-terminal (PTY) process supervisor and circular stream buffer in `src/harness_core/process_registry.py` matching Hermes Agent architecture. This provides thread-safe background process lifecycle management (`spawn`, `poll`, `log`/`read_output`, `wait`, `kill`, `list`), native POSIX pseudo-terminal allocation with transparent pipe fallback, a rolling 200 KB circular ring buffer with non-blocking background reader threads, process state transitions (`RUNNING`, `COMPLETED`, `FAILED`, `KILLED`), and automated `atexit` cleanup to prevent orphan or zombie processes on the host.

  <action>
    Create `src/harness_core/process_registry.py` and implement the foundational data structures and state engine:

    1. Define `ProcessStatus` string enum with states:
       - `RUNNING = "running"`
       - `COMPLETED = "completed"`
       - `FAILED = "failed"`
       - `KILLED = "killed"`

    2. Implement `CircularOutputBuffer`:
       - Default `max_chars = 200_000` (200 KB matching Hermes `MAX_OUTPUT_CHARS`).
       - Internal thread-safe locking (`threading.Lock`).
       - `append(text: str) -> None`: Appends text, increments `total_chars`, and trims from the head if buffer length exceeds `max_chars` (`self._buffer = self._buffer[-self.max_chars:]`).
       - `read(offset: int = 0, limit: int = 2000) -> tuple[str, int, bool]`: Returns `(slice_text, total_chars, has_more)`. Offset indexing supports relative positioning from start of cumulative stream or current buffer window.
       - `get_tail(n: int = 2000) -> str`: Returns the last `n` characters with ANSI escape sequences stripped or intact.
       - `clear() -> None`: Resets buffer.

    3. Implement `ProcessSession` dataclass:
       - Fields: `id` (e.g. `proc_<hex12>`), `command: str`, `cwd: str`, `pid: int | None`, `status: ProcessStatus`, `started_at: float`, `finished_at: float | None`, `exit_code: int | None`, `pty_enabled: bool`, `buffer: CircularOutputBuffer`, `pty_master_fd: int | None`, `process: subprocess.Popen | Any | None`, `_reader_thread: threading.Thread | None`, `_stop_event: threading.Event`.
       - Method `to_dict() -> dict[str, Any]` returning clean serializable dictionary representation (including uptime in seconds, exit_code, status, total_output_chars).
       - Method `mark_finished(exit_code: int, status: ProcessStatus | None = None) -> None`.

    AVOID: Unbounded string growth or holding locks during blocking I/O.
    USE: Monotonic timestamps and thread-safe buffer mutations.
  </action>

  </verify>

<task type="auto">
  <name>ProcessRegistry Lifecycle, PTY Allocation, and Reader Threads</name>
  <files>
    src/harness_core/process_registry.py
    tests/test_process_registry.py
  </files>
  <action>
    Implement `ProcessRegistry` class in `src/harness_core/process_registry.py` with complete POSIX PTY allocation and subprocess supervision:

    1. Process Registry Initialization & Singleton:
       - `_processes: dict[str, ProcessSession] = {}` protected by `threading.RLock()`.
       - Global / singleton accessor `get_process_registry() -> ProcessRegistry`.
       - Register `atexit.register(self.cleanup_all)` on initialization to ensure zero orphaned background processes or open pseudo-terminal file descriptors on exit.

    2. Spawn & PTY Allocation:
       - `spawn(command: str, cwd: str | None = None, env: dict[str, str] | None = None, use_pty: bool = True) -> ProcessSession`:
         - Generate unique ID `proc_<12-hex-chars>`.
         - If `use_pty` is True and POSIX `pty.openpty()` is available (Darwin / Linux):
           - Open master/slave pair using `pty.openpty()`.
           - Set raw terminal mode or sane termios attributes (`TERM=xterm-256color`, `PAGER=cat`, `GIT_PAGER=cat`).
           - Spawn subprocess with `stdin=slave`, `stdout=slave`, `stderr=slave`, `preexec_fn=os.setsid`, `close_fds=True`.
           - Close slave fd in parent process.
           - Record `pty_master_fd = master`.
         - Pipe Fallback:
           - If `pty` fails or platform is Windows or non-pty environment, spawn via `subprocess.Popen(..., stdin=subprocess.DEVNULL, stdout=subprocess.PIPE, stderr=subprocess.STDOUT, text=False, start_new_session=True)`.
           - Set `pty_enabled = False`.

    3. Background Reader Thread:
       - Spawn background daemon thread `_reader_loop(session)`:
         - Uses non-blocking read or `select.select([fd], [], [], 0.1)` on POSIX.
         - Decodes raw bytes using incremental UTF-8 decoder (`codecs.getincrementaldecoder("utf-8")(errors="replace")`).
         - Appends decoded text chunks to `session.buffer`.
         - Detects EOF when child exits; reaps process exit code (`os.waitpid` or `proc.wait()`), updates status (`COMPLETED` if code==0 else `FAILED`), marks `finished_at`, closes file descriptors, and stops thread.

    4. Process Operations:
       - `poll(process_id: str) -> dict[str, Any]`: Checks if running process has terminated, updates status, returns session dict.
       - `read_output(process_id: str, offset: int = 0, limit: int = 2000) -> dict[str, Any]`: Returns `{"process_id": id, "status": status, "output": slice, "offset": offset, "limit": limit, "total_chars": total, "has_more": has_more, "exit_code": code}`.
       - `wait(process_id: str, timeout: float | None = None) -> dict[str, Any]`: Blocks until process finishes or timeout expires; returns session dict.
       - `kill(process_id: str, force: bool = False) -> dict[str, Any]`: Sends `SIGTERM` (or `SIGKILL` if `force=True` or on timeout). On POSIX, signals entire process group `os.killpg(os.getpgid(pid), signal.SIGTERM)` to prevent orphaned child trees. Reaps exit code and marks status `KILLED`.
       - `list_processes(status_filter: str | None = None) -> list[dict[str, Any]]`: Returns list of process dictionaries sorted by start time.
       - `cleanup_all()`: Iterates through all running processes, sends SIGTERM then SIGKILL if alive, closes all open master fds, and joins reader threads with 1.0s timeout.

    5. Authored Unit Test Suite in `tests/test_process_registry.py`:
       - Test buffer ring rollover (200 KB cap).
       - Test fast-exiting command (`echo "hello"`, exit code 0, status `completed`).
       - Test failing command (`exit 42`, exit code 42, status `failed`).
       - Test streaming background command (`python -c "import time; ..."` with incremental `read_output`).
       - Test process termination via `kill(..., force=False)` and `kill(..., force=True)`.
       - Test `cleanup_all` and `atexit` safety.

    AVOID: Zombie processes or hanging on blocking stdin/stdout reads after child termination.
    USE: Non-blocking reads with `select` and `os.killpg` for clean process group teardown.
  </action>
  <verify>
    .venv/bin/python -m unittest tests/test_process_registry.py
  </verify>
  <done>
    `ProcessRegistry` successfully spawns, buffers, polls, reads, waits, kills, and reaps background processes in PTY and pipe modes, passing all unit tests.
  </done>
</task>
