# Plan 38-02: Dual-Pane Shell, Session Picker & Message Feed

<objective>
Implement the dual-pane desktop shell with collapsible left sidebar (workspace selector, session history with relative times, provider status chip) and the streaming conversation feed (user message cards, assistant responses, collapsible `<think>` reasoning folds, distinct tool call cards with inline diffs, and multiline prompt composer with token gauge).
</objective>

<tasks>
<task>
<name>1. Implement Dual-Pane Shell Layout & Left Sidebar Navigation</name>
<files>
App/hex-desktop/src/lib.rs
App/hex-desktop/src/ui/mod.rs
App/hex-desktop/src/ui/shell.rs
App/hex-desktop/src/ui/sidebar.rs
App/hex-desktop/src/ui/session_list.rs
</files>
<action>
1. Create `App/hex-desktop/src/ui/mod.rs` and `src/ui/shell.rs`:
   - Define `AppShell`: Top-level GPUI view splitting viewport horizontally into:
     - Left pane: `SidebarView` (width 260px, collapsible with `Cmd+B`).
     - Right pane: `MainView` (flex-1 fill, hosting message feed and bottom composer).
   - Add split-view divider with subtle border (`border_subtle`).
2. Create `App/hex-desktop/src/ui/sidebar.rs`:
   - Top Workspace Header: Displays project directory name, folder icon, and git branch pill (`main`, `experimental-features`).
   - "New Chat" Trigger Button: Prominent button styled with elevated card background (`#27272a`), compose icon, and `⌘N` keyboard badge.
   - Session Search Field: Filter input for searching past sessions by title.
   - Pinned Sessions Section: Pinned bookmarks with quick-switch affordance.
   - Provider Status Chip (`status-dot`):
     - Displays connection state: Green (Connected / Idle), Amber (Generating / Tool Running), Red (Offline / Error).
     - Label showing active provider & model (e.g., `Anthropic Claude 3.7 Sonnet`).
   - Bottom Settings & Profile footer.
3. Create `App/hex-desktop/src/ui/session_list.rs`:
   - Render recent sessions grouped by date: "Today", "Yesterday", "Previous 7 Days".
   - Relative timestamp formatting using `chrono` ("just now", "12m ago", "3h ago", "2d ago").
   - Selected session highlight: `bg-zinc-800` background with active left border indicator.
   - Hover and context menu triggers for session rename, archive, and delete.
</action>

cargo check -p hex-desktop
</verify>

Dual-pane shell renders with 260px collapsible sidebar, workspace selector, new chat trigger, session list with relative timestamps, and provider status dot.
</done>
</task>

<task>
<name>2. Implement Message Feed, Collapsible Reasoning Folds & Tool Call Cards</name>
<files>
App/hex-desktop/src/ui/feed.rs
App/hex-desktop/src/ui/message.rs
App/hex-desktop/src/ui/reasoning.rs
App/hex-desktop/src/ui/tool_card.rs
App/hex-desktop/src/ui/diff_view.rs
</files>
<action>
1. Create `App/hex-desktop/src/ui/feed.rs` and `src/ui/message.rs`:
   - `MessageFeed`: Scrollable GPUI container with smooth momentum scrolling and auto-scroll to bottom on streaming token delivery.
   - `UserMessageCard`: Clean card aligned to the right/center with `#18181b` background, rounded corners, user avatar/badge, message body, and timestamp.
   - `AssistantMessageView`: Left-aligned response rendering markdown prose, code blocks with syntax highlighting tokens, and action bar (copy, regenerate, branch).
2. Create `App/hex-desktop/src/ui/reasoning.rs`:
   - `ThinkingDisclosure`: Collapsible `<think>` reasoning block:
     - Header row with disclosure caret (`▾` / `▸`), brain/sparkle glyph, and elapsed timer text (`ActivityTimerText`).
     - Dynamic status text: "Thinking..." with shimmer pulse when generating; "Thought for 6s" or "Thought briefly" when settled.
     - Expandable content box with monospace font, muted text (`#a1a1aa`), and left border accent.
     - State tracking: Default collapsed or auto-expanded based on session preference.
3. Create `App/hex-desktop/src/ui/tool_card.rs` and `src/ui/diff_view.rs`:
   - `ToolCallCard`:
     - Tool header: tool badge icon (`terminal`, `file_edit`, `read_file`), tool name, status indicator (spinning loader, checkmark, error cross), and execution duration.
     - Collapsible command input / parameters panel.
     - Collapsible stdout/stderr result box with ANSI color support.
   - `DiffView`:
     - Integrates `hex_protocol::diff::UnifiedDiff`.
     - Displays file path header with diff summary (`+12 -4`).
     - Line-by-line diff formatting:
       - Added lines: sage green foreground (`#8fbf93`) on sage tint background (`rgba(0x8fbf93, 0.12)`), `+` gutter prefix.
       - Deleted lines: rose red foreground (`#c98b8b`) on rose tint background (`rgba(0xc98b8b, 0.10)`), `-` gutter prefix.
       - Context lines: muted text on neutral card background.
       - Dual line numbers (old line / new line).
</action>

     - Key event binding: `Enter` to submit, `Shift+Enter` for line break, `Cmd+Enter` forced submit.
     - Clear button (`×`) when text is present.
2. Create `App/hex-desktop/src/ui/token_gauge.rs`:
   - `TokenGaugeWidget`:
     - Visual progress bar using block characters: `▕██████░░░░░░░░░░▏`.
     - Displays formatted token count: e.g., `24.5k / 128k (19%)`.
     - Dynamic threshold styling:
       - Normal (< 70%): Muted zinc text (`#71717a`) and electric blue fill (`#7aa7ff`).
       - Warning (70–90%): Amber text and fill (`#f59e0b`).
       - Critical (> 90%): Rose red text and fill (`#c98b8b`).
3. Create `App/hex-desktop/src/ui/model_pill.rs`:
   - `ModelSelectorPill`:
     - Compact pill button embedded in the composer bottom bar.
     - Displays provider logo dot, model name (e.g. `Claude 3.7 Sonnet`), and chevron down (`▾`).
     - Click event dispatches the Model Picker modal toggle.
   - Send Button: Circular or rounded button with arrow-up icon; disabled when input is blank or stream is running; stops generation when active.
4. Author comprehensive test suite in `App/hex-desktop/tests/test_feed_and_composer.rs`:
   - Verify token gauge string formatting and percentage threshold transitions (0%, 50%, 85%, 95%).
   - Verify reasoning fold toggle state (expanded vs collapsed).
   - Verify diff line classification (addition, deletion, context) and color assignment.
   - Verify message feed data models and serialization.
