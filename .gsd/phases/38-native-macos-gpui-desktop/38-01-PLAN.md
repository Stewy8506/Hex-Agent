# Plan 38-01: Crate Initialization, Metal Pipeline & Hermes Design System

<objective>
Initialize `App/hex-desktop` as an active Cargo workspace member using Zed's `gpui` framework configured for native macOS Metal acceleration at 120 FPS, and implement the complete Hermes Design System (Dark Zinc palette, translucent vibrancy, and typography hierarchy) with comprehensive test coverage.
</objective>

<tasks>
<task>
<name>1. Initialize hex-desktop Crate, Workspace Registration & Metal Window Configuration</name>
<files>
Cargo.toml
App/hex-desktop/Cargo.toml
App/hex-desktop/src/lib.rs
App/hex-desktop/src/main.rs
App/hex-desktop/src/window.rs
</files>
<action>
1. Update root `Cargo.toml`:
   - Add `"App/hex-desktop"` to the `workspace.members` array.
2. Create `App/hex-desktop/Cargo.toml`:
   - Package name: `hex-desktop`, version `0.1.0`, edition `2021`.
   - Dependencies:
     - `gpui = "0.2.2"`
     - `hex-protocol = { path = "../hex-protocol" }`
     - `serde = { version = "1.0", features = ["derive"] }`
     - `serde_json = "1.0"`
     - `tokio = { version = "1.0", features = ["full"] }`
     - `chrono = { version = "0.4", default-features = false, features = ["clock", "std"] }`
     - `anyhow = "1.0"`
     - `futures = "0.3"`
   - Dev-dependencies:
     - `tempfile = "3.8"`
   - Binary target: `src/main.rs`, Library target: `src/lib.rs`.
3. Create `App/hex-desktop/src/window.rs`:
   - Define `WindowConfig`:
     - Default dimensions: width 1200px, height 800px, minimum size 900x600px.
     - Window bounds: centered on primary active display.
     - Window options: macOS Metal rendering configuration with `TitlebarOptions` (`appears_transparent: true`, `traffic_light_position: Some(point(px(14.0), px(16.0)))`), and `WindowBackgroundAppearance::Blurred` for native macOS window vibrancy.
   - Define `DesktopWindow`: Root GPUI view holding workspace context and view dispatch state.
4. Create `App/hex-desktop/src/main.rs` and `src/lib.rs`:
   - App bootstrap initializing `gpui::App::new()` and opening main window with `WindowOptions`.
   - Export public modules: `theme`, `window`.
</action>
<verify>
cargo check -p hex-desktop
</verify>
<done>
App/hex-desktop is added to Cargo workspace, compiles cleanly with GPUI and hex-protocol dependencies, and defines native macOS Metal window options.
</done>
</task>

<name>2. Implement Hermes Design System Tokens, Zinc Palette & Typography</name>
<files>
App/hex-desktop/src/theme.rs
App/hex-desktop/src/lib.rs
</files>
<action>
1. Create `App/hex-desktop/src/theme.rs`:
   - Port the Hermes Dark Zinc color palette matching `benchmarks/hermes-agent/apps/desktop/` and `Hex agent TUI.html`:
     - Canvas Background: `gpui::rgb(0x09090b)` (`#09090b` canvas dark)
     - Card / Surface Background: `gpui::rgb(0x18181b)` (`#18181b` zinc-900)
     - Card Elevated / Hover: `gpui::rgb(0x27272a)` (`#27272a` zinc-800)
     - Border Low / Subtle: `gpui::rgb(0x27272a)` (`#27272a`)
     - Border Mid / Structural: `gpui::rgb(0x3f3f46)` (`#3f3f46` zinc-700)
     - Primary Text: `gpui::rgb(0xfafafa)` (`#fafafa` zinc-50)
     - Secondary / Muted Text: `gpui::rgb(0xa1a1aa)` (`#a1a1aa` zinc-400)
     - Dim / Metadata Text: `gpui::rgb(0x71717a)` (`#71717a` zinc-500)
     - Extra Dim Text: `gpui::rgb(0x52525b)` (`#52525b` zinc-600)
     - Electric Blue / Accent: `gpui::rgb(0x7aa7ff)` (`#7aa7ff`)
     - Sage Green / Addition FG: `gpui::rgb(0x8fbf93)` (`#8fbf93`)
     - Sage Tint / Addition BG: `gpui::rgba(0x8fbf931f)` (12% alpha `#171f18`)
     - Rose Red / Deletion FG: `gpui::rgb(0xc98b8b)` (`#c98b8b`)
     - Rose Tint / Deletion BG: `gpui::rgba(0xc98b8b1a)` (10% alpha `#1c1616`)
     - Warning Amber: `gpui::rgb(0xf59e0b)` (`#f59e0b`)
   - Implement `HermesTheme` struct implementing GPUI global styling helper methods (`theme.canvas_bg()`, `theme.card_bg()`, `theme.border_subtle()`, etc.).
   - Define Typography hierarchy:
     - `font_mono`: `["JetBrains Mono", "SF Mono", "Menlo", "Courier New", "monospace"]`
     - `font_sans`: `["-apple-system", "BlinkMacSystemFont", "SF Pro Text", "system-ui", "sans-serif"]`
     - Font size scales: Title (15px / 600 weight), Body (13px / 400 weight), Code (12px / 400 weight mono), Caption (11px / 400 weight).
   - Define translucency presets: Frosted glass panel fill (`rgba(0x18181b, 0.88)`).
2. Wire `HermesTheme` as a GPUI Global in `App/hex-desktop/src/lib.rs`.
</action>
