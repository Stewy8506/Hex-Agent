     - Warning/shield header with tool name badge (`execute_code`, `bash`, `rm`, `write_file`) and risk classification tag.

     - 3-Way Radio Selection:
       - `[1] Allow once` (hotkey `y`): Approves only this single invocation.

       - `[3] Deny` (hotkey `n`): Rejects execution and halts tool call with cancellation reason.
     - 15-Minute Auto-Approval Lease Toggle:
       - Checkbox: "Grant 15m auto-approval lease for matching commands" (`temporal lease` integration from Phase 37).
       - When checked, attaches lease duration parameter to approval decision so subsequent matching commands execute with 0ms delay.
     - Action buttons: "Approve" (primary accent) and "Deny" (danger rose).
3. Create `crates/hex-desktop/src/ui/modals/palette.rs`:
   - `CommandPaletteModal`:
     - Top search input with search icon, auto-focused, handling fuzzy filtering.
     - Grouped command entries:
       - `Actions`: "New Chat", "Clear History", "Export Transcript", "Compact Context".
       - `Navigation`: "Open Settings", "Switch Workspace", "Toggle Sidebar".
       - `Sessions`: Recent session search results with matching highlight.
     - Keyboard navigation: `Up` / `Down` arrows move selection highlight; `Enter` executes command; `Esc` closes.
4. Create `crates/hex-desktop/src/ui/modals/model_picker.rs`:
   - `ModelPickerModal`:
     - Searchable list of models grouped by provider: Anthropic (`Claude 3.7 Sonnet`, `Claude 3.5 Haiku`), OpenAI (`GPT-4o`, `o3-mini`), Local MLX/Ollama (`Qwen 2.5 Coder 32B`, `Llama 3.3 70B`), OpenRouter.
     - Each entry shows: model name, provider icon, context limit badge (e.g., `128k`, `200k`), latency tier tag, and active checkmark.
     - Selecting a model updates the session model state and updates the composer model pill.
</action>

<name>2. Implement ACP Client Bridge & harness_core Communication</name>
<files>

crates/hex-desktop/src/ui/shell.rs

<action>
1. Create `crates/hex-desktop/src/acp_bridge.rs`:
   - `AcpBridge`: Integration bridge wrapping `hex_protocol::AcpClient`:
     - Connection management: Supports connecting via Unix domain socket (`/tmp/hex-acp.sock`) or spawning child process (`python -m harness_core.client.cli acp`).
     - Handshake: Sends JSON-RPC 2.0 `initialize` request with client capabilities and metadata.
     - Outbound calls:
       - `new_session(workspace_root)` -> returns `session_id`.
       - `send_prompt(session_id, text)` -> dispatches user prompt into ReAct loop.
       - `cancel_session(session_id)` -> interrupts running generation.
       - `send_approval_decision(request_id, decision, lease_grant)` -> returns operator decision to backend.
     - Inbound notification handler (running on background Tokio task and forwarding to GPUI event loop):
       - `session/update`: Dispatches streaming text tokens to active dialogue.
       - `tool/call`: Dispatches tool invocation notification, adding tool card to feed.
       - `tool/result`: Updates tool card with execution output, returncode, or diff.
       - `approval/request`: Dispatches approval request event, opening `ToolApprovalModal`.
       - `status`: Updates provider status chip with backend health state.
     - Automatic reconnect loop with exponential backoff on disconnect.
2. Wire `AcpBridge` into `AppShell` in `crates/hex-desktop/src/ui/shell.rs`.
</action>
