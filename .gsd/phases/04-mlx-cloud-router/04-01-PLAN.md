# Plan 04.01: Local MLX Model Provider & Live Log Compression Engine

<objective>
Implement the base `ModelProvider` protocol, telemetry contracts, and `LocalMLXModelProvider` in `src/harness_core/providers/mlx_provider.py` (and `base.py`). The local MLX runner discovers Apple Silicon M4 unified memory architecture, dynamically loads `mlx_lm` quantized models for local inference, and implements a high-performance Tier-1 Context & Log Compressor that distills verbose pytest and build traces (>20,000 tokens) into dense failure summaries (>70% token reduction) with 100% preservation of failing file paths, line numbers, and assertion messages. If `mlx_lm` or weights are not installed, a resilient pure-Python fallback engine guarantees zero dependency breakage across any host environment. Validate functionality with comprehensive unit and contract tests in `tests/test_model_providers.py`.

Purpose: Enable zero-cost local inference and live log compression on Apple Silicon M4 while keeping sensitive data 100% local and protecting cloud token budgets.
Output: Core `ModelProvider` protocol, `LocalMLXModelProvider`, `Tier1LogCompressor`, and contract test suite in `tests/test_model_providers.py`.
</objective>

<task type="auto">
  <name>Implement Tier-1 Context & Log Compressor engine with AST/trace parsing and >70% token reduction</name>
  <files>src/harness_core/providers/mlx_provider.py</files>
  <action>
    Implement `Tier1LogCompressor` and wire it into `LocalMLXModelProvider` in `src/harness_core/providers/mlx_provider.py`:
    1. Implement `Tier1LogCompressor`:
       - Method `compress(raw_log: str, max_chars: int = 2400) -> dict[str, Any]`:
         - Applies `redact_secrets` to sanitize API keys, credentials, and passwords from log content.
         - Computes `raw_tokens = max(1, len(sanitized_log) // 4)`.
         - Trace & Failure Frame Isolation:
           - Identifies test failure markers: `=== FAILURES ===`, `FAIL:`, `ERROR:`, `FAILED ...`, `AssertionError`.
           - Extracts failing test function names: e.g. `test_[\w]+`.
           - Extracts exact source file locations and line numbers using regex patterns:
             `File "([^"]+)", line (\d+)` and `([a-zA-Z0-9_\-\./]+\.py):(\d+)`.
           - Extracts traceback call frames (capturing the bottom frames where failure originated).
           - Extracts assertion statements and error diffs:
             `AssertionError: ...`, `E\s+assert\b.*`, `E\s+\+.*`, `E\s+\-.*`, `Exception: ...`, `IndexError: ...`, `KeyError: ...`, `ValueError: ...`.
           - Strips noisy passing test dots (`.`), percentage indicators (`[ 42%]`), `PASSED`, `SKIPPED`, pytest environmental headers, and trailing summary bars.
         - AST / Source Context Extraction:
           - If a failing file exists locally on disk, inspects the target line to extract failure context if omitted by the raw log.
         - Dense Formatting:
           - Assembles compact failure summary formatted as:
             ```
             [Tier-1 M4 Compressed Failure Digest]
             FAILED: <test_name>
             LOCATION: <file_path>:<line_number>
             FRAME: <function_or_caller>
             ASSERTION: <assertion_expression>
             DIFF: <expected vs actual>
             ```
           - If text exceeds `max_chars`, truncates while preserving all failure headers, locations, and assertion errors.
         - Token Reduction Metrics:
           - Computes `compressed_tokens = max(1, len(compressed_text) // 4)`.
           - Computes `token_savings_pct = round(max(0.0, (1.0 - (compressed_tokens / raw_tokens)) * 100.0), 2)`.
           - Guarantees >70% token savings on verbose traces (>1,200 characters).
           - Returns dictionary:
             ```python
             {
                 "compressed_text": compressed_text,
                 "raw_tokens": raw_tokens,
                 "compressed_tokens": compressed_tokens,
                 "token_savings_pct": token_savings_pct,
                 "failing_files": failing_files,
                 "failing_assertions": failing_assertions,
                 "engine": "tier1_mlx_fallback" if not self.is_mlx_available() else "tier1_mlx",
             }
             ```
    2. Wire `LocalMLXModelProvider.compress_log(self, raw_log: str, max_chars: int = 2400) -> dict[str, Any]` delegating to `Tier1LogCompressor`.
    3. Ensure zero external dependencies: pure Python regex and AST parsing executes in < 5 ms on any machine.
    AVOID: Naive head-tail truncation that cuts off vital traceback frames or assertion messages in large logs.
  </action>
  <verify>python3 -c "from harness_core.providers.mlx_provider import LocalMLXModelProvider; p = LocalMLXModelProvider(); res = p.compress_log('PASSED test_1.py\n'*50 + 'FAILED test_math.py:42: test_add\n    assert 2 + 2 == 5\nAssertionError: assert 4 == 5\n' + 'PASSED test_2.py\n'*50); print('Token savings:', res['token_savings_pct'], '%, Assertions:', res['failing_assertions'])"</verify>
  <done>Tier-1 Context & Log Compressor distills verbose logs, preserves 100% of failing file paths, line numbers, and assertions, and achieves >70% token reduction.</done>
