# Plan 04.02: Cloud API Connectors, Per-Task Budget Ceilings, Privacy Gating & Router Integration

<objective>
Implement `CloudModelProvider` in `src/harness_core/providers/cloud_provider.py` supporting Anthropic Claude, OpenAI, and Google Gemini via a unified `ModelProvider` contract. Implement per-task budget tracking (USD cost ceiling, output token cap, and request count limits), strict privacy gating that blocks cloud egress for `sensitive` and `secret` classifications (raising `PolicyBlockedError`), and automatic outbound secret scrubbing. Integrate `LocalMLXModelProvider` as Tier-1 Gatekeeper and `CloudModelProvider` as Tier-2 Heavy Reasoner into `TwoTierModelRouter` in `src/harness_core/router.py`, capturing execution telemetry (latency, tokens, cost, compression ratio) in `RouteDecision` metadata. Author comprehensive tests in `tests/test_model_providers.py` and a real 500-line pytest compression and privacy benchmark in `tests/test_two_tier_compression_benchmark.py`.

Purpose: Provide governed, budget-capped access to frontier cloud models while guaranteeing zero secret leaks and keeping private data 100% local.
Output: Cloud provider connector, budget enforcer, updated TwoTierModelRouter, and end-to-end benchmark test suite.
</objective>

  <action>
    Create `src/harness_core/providers/cloud_provider.py` providing governed cloud model access:
    1. Define `CloudProviderType(str, Enum)`: `ANTHROPIC = "anthropic"`, `OPENAI = "openai"`, `GEMINI = "gemini"`.
    2. Define `ModelPricing`:
       - Standard pricing lookup per 1M tokens:
         - Anthropic Claude 3.5 Sonnet: $3.00 input, $15.00 output.
         - OpenAI GPT-4o: $2.50 input, $10.00 output.
         - Google Gemini 1.5 Pro: $1.25 input, $5.00 output.
         - Google Gemini 3.5 Pro: $1.50 input, $6.00 output.
       - Helper `calculate_cost_usd(model_id: str, input_tokens: int, output_tokens: int) -> float`.
    3. Implement `TaskBudgetTracker`:
       - Tracks cumulative `total_cost_usd: float = 0.0`, `total_input_tokens: int = 0`, `total_output_tokens: int = 0`, and `request_count: int = 0`.
       - Configurable limits: `max_cost_usd: float = 2.0`, `max_output_tokens: int = 65536`, `max_requests: int = 50`.
       - Method `check_budget_before_call()`:
         - If `request_count >= max_requests`, raises `BudgetExceededError(f"Task request count limit exceeded: {request_count} >= {max_requests}")`.
         - If `total_cost_usd >= max_cost_usd`, raises `BudgetExceededError(f"Task cost ceiling exceeded: ${total_cost_usd:.4f} >= ${max_cost_usd:.2f}")`.
       - Method `record_usage(input_tokens: int, output_tokens: int, cost_usd: float)`:
         - Increments cumulative stats.
         - If `total_cost_usd > max_cost_usd` or `total_output_tokens > max_output_tokens`, raises `BudgetExceededError`.
    4. Implement `CloudModelProvider(ModelProvider)`:
       - `provider_id = "cloud_frontier"`
       - `provider_type: CloudProviderType | str` (default: `"gemini"`).
       - `model_id: str = "gemini-3.5-pro"` (configurable).
       - `api_key: str | None = None` (loads from env: `GEMINI_API_KEY`, `ANTHROPIC_API_KEY`, `OPENAI_API_KEY` if not passed).
       - `budget_tracker: TaskBudgetTracker` (instantiated per provider or injected per task).
       - Pluggable transport: accepts optional `http_transport: Callable[[str, dict[str, str], bytes], tuple[int, bytes]]` for testing/mocking without network calls, defaults to stdlib `urllib.request`.
       - Method `generate(prompt: str, *, system_prompt: str | None = None, max_tokens: int = 1024, temperature: float = 0.0, data_classification: str = "internal", budget: TaskBudget | None = None, **kwargs: Any) -> ModelResponse`:
         - Privacy Gate: If `data_classification in ("sensitive", "secret")`:
           - Immediately raises `PolicyBlockedError(f"Cloud egress forbidden for data classification '{data_classification}'. Data must remain within 100% local boundary.")` with ZERO network attempts.
         - Secret Redaction: Runs `redact_secrets(prompt)` and `redact_secrets(system_prompt)` to sanitize API keys and credentials before constructing outbound payloads.
         - Budget Pre-flight: Validates limits against `self.budget_tracker`. If a task-specific `TaskBudget` is provided, syncs ceilings.
         - Dispatch: Formats request payload based on `provider_type`:
           - Anthropic: `{"model": self.model_id, "messages": [{"role": "user", "content": clean_prompt}], "max_tokens": max_tokens}` with headers `x-api-key`, `anthropic-version`.
           - OpenAI: `{"model": self.model_id, "messages": [{"role": "user", "content": clean_prompt}], "max_tokens": max_tokens}` with `Authorization: Bearer <key>`.
           - Gemini: `{"contents": [{"role": "user", "parts": [{"text": clean_prompt}]}], "generationConfig": {"maxOutputTokens": max_tokens}}`.
         - Execution & Response: Measures `latency_ms`, parses text and token counts, calculates `cost_usd`, updates `self.budget_tracker`, returns `ModelResponse`.
    5. Create `src/harness_core/cloud_provider.py` and update `src/harness_core/providers/__init__.py` re-exporting `CloudModelProvider`, `TaskBudgetTracker`, `CloudProviderType`.
    AVOID: Unsanitized outbound HTTP calls that could leak credentials; always run `redact_secrets` before serialization.
  </action>
