</objective>

<tasks>
<task>
<name>1. App State Extensions for Mockup Screens</name>
<action>
Extend `crates/hex-tui/src/app.rs`:
1. Add `ScreenState { Start, Session }` and `app.screen_state`.
2. Add data models:
   - `PlanStep { title: String, status: StepStatus }` (`Completed`, `Active`, `Pending`).
   - `ChangedFile { path: String, additions: usize, deletions: usize }`.

3. Add right-rail telemetry:
   - `tokens_used: usize`, `max_tokens: usize` (default 76k / 200k = 38%).
   - `modified_files_count: usize`, `indexed_files_count: usize`.
4. Add input switching: submitting prompt on Start screen transitions to Session screen.

<task>
<name>2. Implement Screen 0: Start / Welcome View</name>
<action>
Create `crates/hex-tui/src/ui/screens/start.rs`:
1. Centered vertical column within terminal area.
2. `StartWordmark` widget rendered in `theme.text_bright`.
3. Workspace path: `~/projects/` (`theme.text_dim`) + `workspace_name` (`theme.text_bright`, bold).
4. Telemetry: `branch · N modified · N files indexed` separated by `·` in `theme.text_extra_dim`.
5. Angled/rounded prompt container:
   - Border in `theme.border_mid`.
   - Top line: `> ` prompt + cycling placeholder phrase (`Describe what to build or fix`) + blinking blue cursor.
   - Bottom line: `build · sonnet` ... `enter send`.
6. Shortcut badges centered below prompt:
   - `/ commands` | `@ files` | `tab agent` | `ctrl+r history`.
7. `resume` section:
   - Section header: `resume` in `theme.text_dim`.
   - Interactive rows with selection highlight (`theme.hover_bg` on selection).
</action>
