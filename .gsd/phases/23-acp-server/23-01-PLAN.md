  <action>
    Create `src/harness_core/acp.py`:
    1. Define JSON-RPC 2.0 message structures:
       - `ACPRequest`: `jsonrpc="2.0"`, `id`, `method`, `params`.
       - `ACPResponse`: `jsonrpc="2.0"`, `id`, `result`, `error`.
       - `ACPNotification`: `jsonrpc="2.0"`, `method`, `params`.
    2. Implement `ACPSession`:
       - `session_id: str`, `workspace_root: Path`, `model: str`, `task_history: list[dict]`, `cancelled: bool`.
    3. Implement `ACPServer`:
       - `__init__(orchestrator: HarnessOrchestrator | None = None, workspace_root: Path | str | None = None)`
       - JSON-RPC protocol dispatch:
         - `initialize`: returns server info (`name="HEX"`, `version="0.20.1"`, `capabilities`: `tools`, `session`, `prompts`).
         - `session/new`: initializes a new `ACPSession` bound to client cwd.
         - `session/prompt`: executes task via `orchestrator`, streams progress notifications (`session/update`), returns completion summary.
         - `session/cancel`: requests interruption of the active task.
         - `session/list`: lists active/historical sessions.
         - `tools/list`: returns tools from `ToolGateway.list_tool_definitions()`.
         - `tools/call`: invokes specific tool through `ToolGateway.invoke()`.
       - Stdio transport:
         - Reads messages line-by-line or with `Content-Length` header framing from `sys.stdin`.
         - Writes formatted JSON-RPC responses to `sys.stdout` followed by newline.
         - Redirects all standard logging to `sys.stderr`.
  </action>

  </verify>
