# Plan 08.02: One-Key Keyboard Approvals, Interactive Sandbox Shell & `hex init` Polish

<objective>

  <name>Implement One-Key Keyboard Approvals and Isolated CoW Sandbox Shell in HexConsole</name>
  <files>src/harness_core/tui.py</files>
  <action>
    Enhance `HexConsole` in `src/harness_core/tui.py` to intercept `ApprovalRequiredInterrupt` and handle interactive one-key approvals:
    1. Intercept `ApprovalRequiredInterrupt` in `HexConsole`:
       - Wrap task submission / execution invocations in a try-except catching `ApprovalRequiredInterrupt`.
       - When caught, delegate to `handle_approval_prompt(apr_interrupt, prompt_fn=..., shell_runner=...)`.
    2. Implement `handle_approval_prompt`:
       - Extract `approval = apr_interrupt.approval_record` (`approval_id`, `task_id`, `step_id`, `action_type`, `action_params`, `blast_radius_summary`, `risk_class`).
       - Apply `redact_secrets` to action parameters before rendering.
       - Display a formatted alert panel:
         - Title: `🚨 Approval Required: {action_type} ({risk_class})`
         - Fields: Task ID, Step ID, Risk Class, Blast Radius Summary, Parameters.
         - Instructions: `[y] Approve   [n] Reject   [d] Full Diff   [s] Sandbox Shell   [q] Abort`
       - Interactive prompt loop:
         - Read single key or line (supporting `prompt_fn` override for testing, falling back to `input()`):
         - `y` or `approve`:
           - Call `self.orchestrator.ledger.decide_approval(approval['approval_id'], "APPROVED", decided_by="owner")`.
           - Display confirmation: `✓ Approval recorded. Resuming task execution...`.
           - Call `self.orchestrator.resume_task(approval['task_id'])`.
           - Continue session loop with resumed task.
         - `n` or `reject`:
           - Prompt operator for optional rejection guidance / comment.
           - Call `self.orchestrator.ledger.decide_approval(approval['approval_id'], "REJECTED", decided_by="owner", comment=comment)`.
           - Display notice: `✗ Action rejected by operator.`.
         - `d` or `diff`:
           - Look up active attempt workspace and base checkpoint.
           - Compute dirty file diff using `self.orchestrator.cow.compute_workspace_diff(attempt_ws, base_snap_path)`.
           - Render formatted diff via `render_unified_diff(...)`.
           - Re-display approval prompt options.
         - `s` or `shell`:
           - Identify active attempt workspace directory (`attempt_ws`). If not found, use `self.workspace_root`.
           - Display: `Entering isolated CoW attempt subshell at {attempt_ws} (Type 'exit' to return)...`.
           - Spawn an interactive subshell: if `shell_runner` is provided, call `shell_runner(attempt_ws)`; otherwise call `subprocess.run([os.environ.get("SHELL", "/bin/sh")], cwd=attempt_ws)`.
           - Upon shell exit, display `Returned from subshell.` and re-display approval prompt options.
         - `q` or `abort`:
           - Call `self.orchestrator.cancel_task(approval['task_id'], actor="owner")`.
           - Display notice: `Task aborted by operator; uncommitted CoW changes rolled back.`.

    AVOID: Unhandled exceptions when stdin is EOF, piped, or non-interactive. Ensure `handle_approval_prompt` defaults to aborting or rejecting safely if EOF is encountered unexpectedly.
  </action>
  <verify>
    <command>python3 -c "from harness_core.tui import HexConsole; from harness_core.orchestrator import HarnessOrchestrator; from harness_core.gateway import ApprovalRequiredInterrupt; orch = HarnessOrchestrator(':memory:'); t = orch.ledger.submit_task({'goal': 'test_apr'}); apr = orch.ledger.create_approval(task_id=t['task_id'], attempt_id='att1', step_id='s1', action_type='git_commit', action_params={'message': 'test'}, blast_radius_summary='commit changes', risk_class='R3'); console = HexConsole(orch); res = console.handle_approval_prompt(ApprovalRequiredInterrupt(apr), prompt_fn=lambda _: 'y'); assert res['decision'] == 'APPROVED'; rec = orch.ledger.get_approval(apr['approval_id']); assert rec['decision'] == 'APPROVED'; print('KEYBOARD_APPROVAL_OK')"</command>
  </verify>
  <done>
    `HexConsole` intercepts `ApprovalRequiredInterrupt` and handles `[y]`, `[n]`, `[d]`, `[s]`, `[q]` with ledger recording, task resumption, diff inspection, isolated subshell execution, and clean abort rollback.
  </done>

  <name>Implement Repository Stack Detection & Polish `hex init` Project Scaffolding</name>
  <files>src/harness_core/onboard.py, src/harness_core/cli.py</files>
  <action>
    Add project stack detection and project configuration generation to `src/harness_core/onboard.py` and enhance `hex init` in `src/harness_core/cli.py`:
    1. In `src/harness_core/onboard.py`:
       - Implement `detect_project_stack(repo_root: Path) -> dict[str, Any]`:
         - Scans `repo_root` for canonical stack marker files:
           - Python: `pyproject.toml`, `setup.py`, `requirements.txt`, `pytest.ini` -> `{"stack": "python", "test_cmd": "pytest", "src_dirs": ["src", "lib"], "watch_extensions": [".py"]}`.
           - Node/TypeScript: `package.json`, `tsconfig.json` -> `{"stack": "node", "test_cmd": "npm test", "src_dirs": ["src", "lib"], "watch_extensions": [".js", ".ts", ".jsx", ".tsx"]}`.
           - Rust: `Cargo.toml` -> `{"stack": "rust", "test_cmd": "cargo test", "src_dirs": ["src"], "watch_extensions": [".rs"]}`.
           - Go: `go.mod` -> `{"stack": "go", "test_cmd": "go test ./...", "src_dirs": ["."], "watch_extensions": [".go"]}`.
           - Fallback: `{"stack": "generic", "test_cmd": "make test", "src_dirs": ["."], "watch_extensions": []}`.
       - Implement `init_project(repo_root: Path, *, force: bool = False) -> dict[str, Any]`:
         - Creates `.hex` directory inside `repo_root`.
         - Detects stack info using `detect_project_stack(repo_root)`.
         - Checks if `.hex/config.yaml` exists:
           - If exists and `force` is False: keeps existing file and flags `created: False`.
           - If not exists or `force` is True: writes `.hex/config.yaml`:
             ```yaml
             version: "1.0"
             project:
               name: "{repo_root.name}"
               stack: "{stack_info['stack']}"
             verification:
               test_command: "{stack_info['test_cmd']}"
               timeout_seconds: 120
             graphify:
               max_blast_depth: 2
               pinned_test_filter: "tests/"
             sandbox:
               isolated: true
               allow_network: false
             ```
         - Writes `.hex/.gitignore` if not present:
           ```gitignore
           # HEX Project Ignored Data
           /data/
           tmp/
           *.log
           ```
         - Returns summary dict with `project_name`, `stack`, `test_command`, `config_path`, `gitignore_path`, and `created`.
    2. In `src/harness_core/cli.py`:
       - Update the `init` subparser arguments:
         - `--workspace`: path to project repository root (defaults to current working directory).
         - `--force`: overwrite existing `.hex/config.yaml`.
       - In `if args.cmd == "init":`:
         - Resolve `workspace_root = Path(args.workspace).resolve() if getattr(args, "workspace", None) else Path.cwd()`.
         - Run `proj_meta = init_project(workspace_root, force=getattr(args, "force", False))`.
         - Initialize orchestrator ledger and seed default skills as before.
         - Print structured JSON output combining project setup metadata, ledger status, CoW backend, and seeded skills.

    AVOID: Overwriting user customizations in existing `.hex/config.yaml` without the `--force` flag.
  </action>

  </verify>
  <done>
