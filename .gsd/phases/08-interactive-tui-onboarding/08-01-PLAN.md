  <name>Implement Core TUI Rendering Engine, Diff Visualizers & Graphify Blast-Radius Tree</name>
  <files>src/harness_core/tui.py</files>
  <action>
    Create `src/harness_core/tui.py` providing terminal formatting, visual diff rendering, AST blast-radius tree display, and token streaming:
    1. Rich / ANSI terminal compatibility:
       - Attempt to import `rich.console.Console`, `rich.markdown.Markdown`, `rich.syntax.Syntax`, `rich.table.Table`, `rich.panel.Panel`, `rich.tree.Tree`.
       - If `rich` is installed, use rich widgets for enhanced terminal aesthetics.
       - If `rich` is not installed or when running in pipe/headless mode, provide robust built-in ANSI fallbacks using standard escape codes (`\033[32m` green, `\033[31m` red, `\033[33m` yellow, `\033[36m` cyan, `\033[1m` bold, `\033[0m` reset) and Unicode box-drawing characters.
    2. Diff visualizers:
       - `render_unified_diff(diff_text: str, title: str = "Proposed Changes") -> str`:
         - Parses unified diff text line by line.
         - Highlights chunk headers (`@@ ... @@`) in cyan.
         - Highlights additions (`+...`) in green.
         - Highlights deletions (`-...`) in red.
         - Displays file headers (`--- a/...`, `+++ b/...`) in bold yellow.
         - Returns formatted string or renders rich Panel.
       - `render_side_by_side_diff(old_text: str, new_text: str, filename: str = "file", width: int = 80) -> str`:
         - Uses `difflib.ndiff` or `difflib.unified_diff` to align before/after content into two side-by-side columns with vertical divider `│`.
         - Highlights modified lines in each column.
    3. Active Graphify AST blast-radius tree renderer:
       - `render_blast_radius_tree(blast_radius_data: dict[str, Any]) -> str`:
         - Parses blast-radius dictionary containing `modified_files` (or `modified_symbols`), `direct_callers` (1-hop), `transitive_callers` (2-hop), `pinned_tests`, and `risk_class`.
         - Renders a clean hierarchical tree:
           - Root: `Active Graphify AST Impact Matrix` with risk badge (e.g. `[R2 - Medium Risk]`).
           - Branch 1: `Modified Files / Symbols` with changed function/class names.
           - Branch 2: `1-Hop Direct Callers` (e.g. `auth.py -> session.py:validate_session`).
           - Branch 3: `2-Hop Transitive Callers`.
           - Branch 4: `Pinned Verification Tests` (e.g. `tests/test_auth.py`, `tests/test_session.py`).
    4. Streaming token renderer:
       - `class StreamingTokenRenderer`:
         - Progressive token accumulator with `feed(token: str)` and `flush()`.
         - Detects Markdown code fences (````python ... ````) and renders syntax highlighting once closed, streaming raw tokens as they arrive.
    5. Session banner and status header:
       - `render_session_banner(model_id: str = "claude-3-5-sonnet", compressor_mode: str = "M4 MLX Local", sandbox_backend: str = "bwrap", cow_backend: str = "apfs") -> str`:
         - Formats a compact header box displaying current model, compressor status, sandbox backend, and CoW snapshot mode.

    AVOID: Hard external dependencies that fail to import on minimal systems. Ensure all formatting methods return readable ANSI strings when rich is not present.
  </action>

  <name>Implement HexConsole Interactive REPL with Slash Commands & Wire CLI Subcommand</name>
  <files>src/harness_core/tui.py, src/harness_core/cli.py</files>
  <action>
    Implement `HexConsole` in `src/harness_core/tui.py` and register the `hex chat` subcommand in `src/harness_core/cli.py`:
    1. Implement `HexConsole`:
       - `__init__(self, orchestrator: HarnessOrchestrator, project_id: str = "default", workspace_root: Path | str | None = None, stream: bool = True, model_profile: str | None = None)`:
         - Stores orchestrator, project_id, resolved workspace_root, stream flag, and current model profile.
         - Initializes session state (active task ID, token budget totals, command history).
       - `start(self, input_fn: Callable[[str], str] | None = None) -> int`:
         - Prints `render_session_banner(...)`.
         - Enters prompt loop with prompt text `hex> ` (or `prompt_toolkit.PromptSession` if installed, falling back to `input_fn` or built-in `input()`).
         - Catches `EOFError` and `KeyboardInterrupt` to exit cleanly.
         - Strips whitespace. If line starts with `/`, dispatches to `handle_slash_command(line)`.
         - Otherwise dispatches to `handle_user_prompt(line)`.
       - Slash command handlers:
         - `/help`: prints table of all slash commands with syntax and purpose.
         - `/status`: retrieves active tasks, last completed task, proof bundle, and worker info from `orchestrator.ledger`.
         - `/diff`: inspects dirty uncommitted changes in active attempt workspace vs base snapshot using `orchestrator.cow.compute_workspace_diff` and displays via `render_unified_diff`.
         - `/rollback`: calls `orchestrator.cancel_task(active_task_id)` or rolls back dirty workspace snapshot to pristine base state.
         - `/fork`: splits active task into speculative branches via `orchestrator.fork_speculative_branches`.
         - `/skills`: lists all scanned skills registered in `orchestrator.ledger` with name, risk class (R0-R4), Gate decision, and quarantine status.
         - `/model [name]`: if argument provided, updates model profile (`hybrid`, `local`, `cloud`, or model ID); otherwise prints active model router configuration.
         - `/budget`: displays session token counts, local compression ratio, cache discount, and estimated USD spend.
         - `/clear`: clears the terminal screen using `os.system('clear' if os.name != 'nt' else 'cls')` or ANSI `\033[H\033[2J`.
         - `/quit` or `/exit`: returns 0, terminating the REPL loop.
       - Natural language prompt handling:
         - Submits task via `orchestrator.submit_and_run(TaskSubmitRequest(goal=line, project_id=self.project_id, workspace_root=str(self.workspace_root)))`.
         - If `self.stream` is True, streams progress messages and model tokens.
         - Renders completion status and summary of Proof-Carrying Artifact.
    2. Wire `hex chat` subcommand in `src/harness_core/cli.py`:
       - Add `p_chat = sub.add_parser("chat", help="Start interactive TUI pair-programming console")`:
         - `--project`: project ID (default "default").
         - `--workspace`: workspace path (default None, resolves to repo root).
         - `--model`: model routing profile override (`hybrid`, `local`, `cloud`).
         - `--no-stream`: disable live token streaming.
       - In `main()` dispatch:
         - `if args.cmd == "chat":` instantiate `HexConsole(orch, project_id=args.project, workspace_root=args.workspace, stream=not args.no_stream, model_profile=args.model)` and invoke `console.start()`.

    AVOID: Unhandled prompt exceptions when running non-interactively or in piped tests. Ensure `HexConsole.start()` accepts an optional `input_fn` or handles `sys.stdin.readline` cleanly.
  </action>

  </verify>
  <done>
