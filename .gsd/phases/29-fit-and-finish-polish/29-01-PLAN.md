  <name>Cockpit Widget Wiring & Visual Wrapped Line Scrolling Fix</name>
  <files>crates/hex-tui/src/ui/mod.rs, crates/hex-tui/src/ui/dialogue.rs</files>
  <action>
    1. In `crates/hex-tui/src/ui/mod.rs`:
       - Update vertical layout constraints in `draw()`.
       - Replace the 2-row layout `[Constraint::Min(6), Constraint::Length(3)]` with a responsive 4-tier vertical constraint stack:
         - Top telemetry header: `Constraint::Length(4)` (renders `header::render(frame, app, chunks[0])`). If terminal height is constrained (< 18 rows), collapse header constraint to `Constraint::Length(0)` so transcript retains maximum vertical height.
         - Transcript & diff main viewport: `Constraint::Min(6)` (renders dialogue and optional diff viewer side-by-side or full-width).
         - Persistent status bar: `Constraint::Length(1)` (renders `status_bar::render(frame, app, chunks[2])` immediately above the composer).
         - Composer input box: `Constraint::Length(3)` (renders `input::render(frame, app, chunks[3])`).
    2. In `crates/hex-tui/src/ui/dialogue.rs`:
       - Fix `max_scroll` calculation. Previously, `max_scroll` was computed as `lines.len().saturating_sub(area.height as usize)`, which only counted logical `Line` items. When Ratatui wraps long lines via `Wrap { trim: false }`, the visual rendered rows exceed `lines.len()`. This caused `follow_dialogue = true` to underestimate total visual height, truncating recent assistant response lines at the bottom of the viewport.
       - Calculate total visual rows by iterating through `lines` and computing visual wrapped row counts against `area.width`:
         ```rust
         let width = area.width.max(1) as usize;
         let mut total_visual_lines = 0;
         for line in &lines {
             let line_len: usize = line.spans.iter().map(|s| s.content.chars().count()).sum();
             let rows = if line_len == 0 {
                 1
             } else {
                 (line_len + width - 1) / width
             };
             total_visual_lines += rows;
         }
         let max_scroll = total_visual_lines.saturating_sub(area.height as usize);
         ```
       - Ensure `app.follow_dialogue` scrolls to `max_scroll`, and manual scroll is clamped to `max_scroll`.
    AVOID: Breaking modal overlays (`render_help_overlay` and `approval::render` must retain their full-screen popup geometry).
  </action>
  <verify>cargo test -p hex-tui && cargo run -p hex-tui -- --check</verify>
  <done>Cockpit layout renders header, dialogue/diff, status bar, and input in proper order without overlap; dialogue max_scroll properly accounts for wrapped lines.</done>
</task>
