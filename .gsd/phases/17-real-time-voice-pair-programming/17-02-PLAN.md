  <name>Implement TUI Voice Mode, Status Badges & Spoken Agent Commentary</name>
  <files>src/harness_core/tui.py</files>
  <action>
    In `src/harness_core/tui.py`:
    1. Import `VoiceEngine`, `VoiceConfig`, `clean_text_for_speech` from `harness_core.voice`.
    2. Update `HexConsole.__init__`:
       - Accept `voice_enabled: bool = False`, `voice_name: str | None = None`, `speech_rate: int = 190`.
       - Initialize `self.voice_engine = VoiceEngine(VoiceConfig(tts_enabled=voice_enabled, stt_enabled=voice_enabled, voice_name=voice_name, speech_rate=speech_rate))`.
    3. Update `render_status_bar`:
       - Add optional parameter `voice_status: str | None = None` (e.g., `"ON"`, `"MUTED"`, `"OFF"`).
       - When `voice_status` is provided, insert a styled voice badge into status bar parts:
         - `"ON"`: `colorize_rgb(" 🎙️ ON ", fg=skin.accent_rgb, bg=skin.status_bg_rgb, bold=True)`
         - `"MUTED"`: `colorize_rgb(" 🔇 MUTED ", fg=skin.warn_rgb, bg=skin.status_bg_rgb, bold=True)`
         - `"OFF"`: `colorize_rgb(" 🎙️ OFF ", fg=skin.muted_rgb, bg=skin.status_bg_rgb)`
       - In `HexConsole.get_status_bar`: determine `v_stat = "MUTED" if self.voice_engine.is_muted() else ("ON" if self.voice_engine.config.tts_enabled else "OFF")` and pass to `render_status_bar`.
    4. Implement `/voice` slash command dispatch in `HexConsole.handle_slash_command`:
       - `/voice on`: enables TTS & STT, announces `"Voice mode enabled"`, prints confirmation card.
       - `/voice off`: disables voice mode, calls `voice_engine.stop()`, prints confirmation.
       - `/voice mute`: toggles mute via `self.voice_engine.toggle_mute()`, prints `[Muted]` or `[Unmuted]`.
       - `/voice status`: prints current voice configuration, active backend, speech rate, and hardware detection report.
       - `/voice voice <name>`: sets voice name.
       - `/voice rate <wpm>`: sets speech rate in words per minute.
       - Add `/voice` to `_cmd_help` output and `_setup_readline` candidate list (`/voice`, `/voice on`, `/voice off`, `/voice mute`, `/voice status`).
    5. Automatic spoken commentary:
       - In `HexConsole.handle_user_prompt`: after successful plan generation, task submission, or text response, if `self.voice_engine.config.tts_enabled` and not `self.voice_engine.is_muted()`:
         - Extract a brief conversational summary (first 1-2 sentences of the model output, or task completion summary).
         - Call `self.voice_engine.speak(summary, clean=True)` in background without blocking prompt rendering.
    6. Ensure clean shutdown:
       - In `start()` upon loop exit (or KeyboardInterrupt / EOFError), call `self.voice_engine.shutdown()`.

    AVOID: Blocking the TUI readline loop during speech synthesis; all speech playback must remain strictly backgrounded.
  </action>
  <verify>python -c "from harness_core.tui import HexConsole, render_status_bar; bar = render_status_bar(voice_status='ON'); assert '🎙️ ON' in bar; print('Status bar voice badge verified')"</verify>
  <done>TUI features /voice slash command suite, live microphone/TTS status bar badge, and non-blocking spoken commentary.</done>
