<task type="auto">
  <name>Implement HeadlessBrowserSession & BrowserManager</name>
  <files>src/harness_core/browser.py</files>
  <action>
    Create `src/harness_core/browser.py`:
    1. Define `BrowserAction` enum: `NAVIGATE`, `SNAPSHOT`, `CLICK`, `TYPE`, `SCREENSHOT`, `EVALUATE`, `CLOSE`.
    2. Define `BrowserActionResult` dataclass: `action`, `url`, `title`, `content` (text or accessibility tree), `screenshot_path`, `ok`, `error`.
    3. Implement `HeadlessBrowserSession`:
       - Tracks active page, URL, history, cookies, and DOM state.
       - Implements lightweight CDP / headless driver with graceful Python-native HTML/DOM extraction fallback (`urllib` + parser + snapshot) so tests and offline servers execute without external dependencies.
       - Implements action handlers:
         - `navigate(url: str)`: loads page, updates title and DOM snapshot.
         - `snapshot()`: extracts readable text and accessibility hierarchy (`ariaSnapshot` style).
         - `click(selector: str)`: finds element and triggers click / form submission.
         - `type(selector: str, text: str)`: fills input fields.
         - `screenshot(output_path: Path | None)`: captures rendered page or HTML snapshot.
         - `evaluate(script: str)`: evaluates expression or parses DOM.
    4. Implement `BrowserManager`:
       - Per-task session isolation (`get_or_create_session(task_id)`).
       - Session cleanup (`close_session(task_id)` and `close_all()`).
  </action>
  <verify>
    .venv/bin/python -c "from harness_core.browser import BrowserManager, BrowserAction; print(BrowserAction.NAVIGATE.value)"
  </verify>
  <done>
    `HeadlessBrowserSession` and `BrowserManager` implemented with per-task session isolation and zero-dependency DOM parsing.
  </done>
</task>
