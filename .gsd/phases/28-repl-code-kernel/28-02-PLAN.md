  <action>
    Integrate `code_kernel` into `ToolGateway` and wire context retention into `ReActLoop`:

    1. Register Tool Schema in `TOOL_DEFINITIONS` in `src/harness_core/gateway.py`:
       - `code_kernel`:
         - id: `"code_kernel"`
         - name: `"code_kernel"`
         - description: `"Execute Python code in a persistent interactive REPL kernel that maintains variables and state across turns (R2)."`
         - risk_class: `"R2"`
         - parameters:
           - `code` (string, required): `"Python code snippet or statements to execute."`
           - `reset` (boolean, default=False): `"Whether to reset kernel state and clear all variables before execution."`
           - `timeout` (number, default=30.0): `"Max execution time in seconds before terminating the cell."`

    2. Update `ToolGateway.__init__`:
       - Add parameter `kernel_registry: KernelRegistry | None = None`.
       - Assign `self.kernel_registry = kernel_registry or get_kernel_registry()`.

    3. Implement `_tool_code_kernel(self, workspace_dir: Path, args: dict[str, Any]) -> dict[str, Any]` in `ToolGateway`:
       - Extract `code = str(args.get("code", "")).strip()`. If empty, return error dictionary.
       - Extract `reset = bool(args.get("reset", False))` and `timeout = float(args.get("timeout", 30.0))`.
       - Resolve session owner key: check `getattr(self, "_active_session_key", "")` or active task ID, falling back to `"default"`.
       - Retrieve or create kernel: `kernel, state_reset = self.kernel_registry.get_or_create(owner=owner, cwd=str(workspace_dir), reset=reset)`.
       - Execute cell: `raw_res = kernel.execute(code=code, timeout=timeout)`.
       - Redact secrets: apply `redact_secrets` to `raw_res.get("stdout", "")`, `raw_res.get("stderr", "")`, and `raw_res.get("traceback", "")`.
       - Format stale module warning: if `raw_res.get("stale_modules")`, call `stale_modules_warning(raw_res["stale_modules"])` and attach to result.
       - Assemble result dictionary:
         `status`: `"success"` if `raw_res["status"] == "ok"` else `raw_res["status"]`,
         `output`: combined stdout and stderr (with `--- stderr ---` separator if stderr is present),
         `stdout`: stdout text,
         `stderr`: stderr text,
         `execution_count`: `raw_res.get("execution_count", 1)`,
         `state_reset`: `state_reset`,
         `duration_seconds`: `raw_res.get("duration_seconds", 0.0)`,
         `warning`: warning string if clipped or stale modules detected.
       - Register tool in `_register_builtin_tools` with `RiskClass.R2`.

    4. Wire `ReActLoop` in `src/harness_core/react_loop.py`:
       - Ensure `session_id` or session key is tracked on the loop instance (`self.session_id`) and forwarded to gateway executions.
       - Ensure multi-turn ReAct loop handles `code_kernel` responses, appends execution output to dialogue history, and presents warnings cleanly to the reasoning model.

    AVOID: Unsanitized or unredacted stdout/traceback leaking secrets into model context.
    USE: Strict `redact_secrets` on all kernel outputs before returning to the model or journaling.
  </action>

       - Implement `_cmd_kernel(self, arg: str = "") -> None`:
         - Parse subcommands: `status`, `reset`, `vars` (or `inspect`), `exec <code>`.
         - `status` (default when no arg provided):
           - Queries `kernel_registry` from gateway or global registry.
           - Displays table/list of active kernels: `OWNER`, `CWD`, `PID`, `EXEC COUNT`, `UPTIME`, `LAST USED`.
           - Shows status colors (`RUNNING` green, `DEAD` red).
         - `reset`:
           - Triggers `kernel.reset()` or `kernel_registry.get_or_create(..., reset=True)`.
           - Prints confirmation: `✔ Code kernel reset. State and variables cleared.`
         - `vars` / `inspect`:
           - Executes a non-destructive inspection snippet in the active kernel:
             `"[ (k, type(v).__name__, repr(v)[:60]) for k, v in sorted(GLOBALS.items()) if not k.startswith('_') ]"`
           - Formats variables, types, and values in a Rich `Table` (if `HAS_RICH`) or formatted ANSI columns.
         - `exec <code>`:
           - Executes code snippet in the active kernel and prints formatted stdout/stderr.
       - Update `/help` command output to document `/kernel [status|reset|vars|exec]`.
       - Add `/kernel` to command autocompletion list.
