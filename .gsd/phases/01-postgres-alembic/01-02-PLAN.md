# Plan 01.02: Dual-Driver PostgreSQL Async Engine & Connection Pool Integration

<objective>
Refactor `LedgerStore` in `src/harness_core/db.py` to support dual drivers: zero-dependency SQLite WAL for local development, and an asynchronous PostgreSQL connection pool (`asyncpg` / `SQLAlchemy[asyncio]`) for production, providing both async APIs and sync compatibility facades.

Purpose: Allow the harness to operate out-of-the-box locally without external database services, while seamlessly switching to high-throughput pooled PostgreSQL 16+ when configured with a connection string.
Output: Dual-engine `LedgerStore` with async methods, sync bridge, and dual-driver unit tests.
