# Plan 25-02: `crates/hex-tui` (Ratatui Alt-Screen Cockpit, Differential Renderer & CLI Launcher)

**Phase:** Phase 25 — Native Rust Terminal Cockpit (Ratatui + Crossterm) & Protocol Crate (Hermes Parity Pillar 2)  
**Task:** 25-02  
**Wave:** 2  
**Objective:** Author the native `hex-tui` terminal application in Rust using Ratatui and Crossterm, providing a 60 FPS alt-screen cockpit with dual-buffer differential rendering, collapsible tool call tree nodes, live streaming viewport, unified diff viewer, and integrate with Python CLI (`hex tui` / `hex chat --ratatui`).

---

### Context & Requirements
- `crates/hex-tui`:
  - Dependencies: `ratatui` (0.28+ or 0.29+), `crossterm` (0.28+), `tokio`, `hex-protocol`, `clap` (4.x), `tui-textarea` or custom interactive input buffer.
  - Architecture:
    - `app.rs`: State machine (`App` struct): active session, message history, current prompt input, scroll offsets, focused pane (`Input`, `Dialogue`, `Diff`, `Help`), approval modal state (`ApprovalDialog`).
    - `ui/`:
      - `header.rs`: Sticky top bar with logo, active model, CoW snapshot mode, fencing lease token, and connection status.
      - `dialogue.rs`: Dialogue viewport with markdown-styled text, expandable/collapsible tool calls with duration and exit status.
      - `diff.rs`: Colorized unified/side-by-side diff viewer for proposed CoW patches.
      - `input.rs`: Command prompt with cursor support, command history, and `/` slash-command autocompletion.
      - `status_bar.rs`: Bottom hotkey hints (`[Enter] Send`, `[Tab] Switch Pane`, `[Ctrl+C] Quit`, `[Esc] Close Dialog`).
    - `event.rs`: Asynchronous event loop multiplexing terminal key/mouse events (`crossterm::event`) and backend ACP JSON-RPC notifications from `hex-protocol`.
- Python Integration:
  - In `src/harness_core/cli.py`, add `hex tui` subcommand and `--ratatui` flag to `hex chat`.
  - When invoked, it checks for the compiled `hex-tui` binary (in `crates/hex-tui/target/release` or standard PATH) and spawns it connected to the internal ACP server.
- Tests:
  - Unit tests in `crates/hex-tui` verifying UI rendering, state mutations, and keybindings.
  - Python integration tests in `tests/test_rust_tui_launcher.py`.

---

### Proposed Implementation Tasks
1. Create `crates/hex-tui/Cargo.toml` and binary entrypoint `src/main.rs`.
2. Implement `app.rs`, `event.rs`, and modular UI widgets in `src/ui/`.
3. Support hotkeys (`Tab`, `Esc`, `Enter`, `Ctrl+C`, `y/n` for approvals).
4. Update `src/harness_core/cli.py` to register `hex tui` and `--ratatui`.
5. Author tests in `crates/hex-tui` and `tests/test_rust_tui_launcher.py`.
