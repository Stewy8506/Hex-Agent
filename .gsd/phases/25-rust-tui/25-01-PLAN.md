# Plan 25-01: Cargo Workspace & `crates/hex-protocol` (ACP JSON-RPC Engine & Models)

**Phase:** Phase 25 — Native Rust Terminal Cockpit (Ratatui + Crossterm) & Protocol Crate (Hermes Parity Pillar 2)  
**Task:** 25-01  
**Wave:** 1  
**Objective:** Author root `Cargo.toml` workspace and build `crates/hex-protocol` containing shared ACP JSON-RPC 2.0 client, domain models, session lifecycle, message structures, and diff parser that will be shared between `hex-tui` and our future GPUI desktop app.

---

### Context & Requirements
- `Cargo.toml` root workspace configuring:
  - `members = ["crates/hex-protocol", "crates/hex-tui"]`
  - Shared dependencies: `serde`, `serde_json`, `tokio`, `thiserror`, `anyhow`, `futures`.
- `crates/hex-protocol`:
  - `models.rs`: Strongly typed Rust structs for:
    - `InitializeRequest`, `InitializeResponse`, `ServerInfo`, `ServerCapabilities`
    - `SessionNewRequest`, `SessionNewResponse`, `SessionPromptRequest`, `SessionPromptResponse`, `SessionCancelRequest`
    - `ToolsListResponse`, `ToolDefinition`, `ToolCallRequest`, `ToolCallResponse`
    - `Message`, `Role` (User, Assistant, Tool, System), `Turn`, `SessionStatus`
  - `client.rs`: Asynchronous JSON-RPC 2.0 stdio / socket client:
    - Spawns Python backend (`python3 -m harness_core.cli acp`) or connects to an existing stdio pipe.
    - Handles sequence IDs (`id: 1, 2, ...`), request multiplexing, response matching, and error mapping.
    - Streaming notification listener for live token emission and tool execution progress.
  - `diff.rs`: Clean unified diff parser that converts raw patch strings into structured added/removed/context lines with line numbers for syntax-highlighted renderers.

---

### Proposed Implementation Tasks
1. Create root `Cargo.toml` workspace and `crates/hex-protocol/Cargo.toml`.
2. Implement `crates/hex-protocol/src/models.rs` with full Serde JSON-RPC serialization.
3. Implement `crates/hex-protocol/src/diff.rs` with unified diff parser.
4. Implement `crates/hex-protocol/src/client.rs` with asynchronous stdio JSON-RPC transport.
5. Implement unit tests in `crates/hex-protocol/src/lib.rs` and `crates/hex-protocol/tests/protocol_test.rs`.
