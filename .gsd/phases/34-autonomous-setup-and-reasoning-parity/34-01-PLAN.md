# Plan 34.01: Model Reasoning Effort Engine & Wire Clamping

<objective>
Implement first-class model reasoning effort control in HEX, reaching full parity with Hermes Agent. Build `src/harness_core/reasoning_effort.py` with wire clamping for OpenAI, Anthropic, Gemini, and open-weight models, wire it into `router.py`, `config_loader.py`, `onboard.py`, and `tui.py`, and prove with comprehensive unit tests.

Purpose: Allow operators to control model thinking depth and budget tokens, eliminating blind provider defaults and matching Hermes's /reasoning and setup effort controls.
Output: `reasoning_effort.py`, router/config/onboard/TUI wiring, and `tests/core/test_reasoning_effort.py`.
</objective>

<tasks>
<task>
<name>1. Implement Reasoning Effort Vocabulary & Clamping Engine</name>
<action>
Create `src/harness_core/reasoning_effort.py` with:
1. Canonical ladder: `EFFORT_LADDER = ("none", "minimal", "low", "medium", "high", "xhigh", "max")`.
2. Vocabulary sets per provider:
   - `OPENAI_EFFORTS = ("low", "medium", "high")`
   - `ANTHROPIC_EFFORTS = ("none", "low", "medium", "high", "max")`
   - `GEMINI_EFFORTS = ("none", "low", "medium", "high")`
   - `DEEPSEEK_EFFORTS = ("none", "low", "medium", "high", "max")`
3. Function `clamp_effort(effort: str, supported: Sequence[str]) -> str`:
   - Returns verbatim if supported; otherwise selects the nearest weaker supported level (or lowest if none weaker).
4. Function `effort_to_anthropic_thinking(effort: str) -> dict | None`:
   - Maps low -> 2,048, medium -> 8,192, high -> 16,384, max -> 32,768 budget tokens. Returns None for "none".
5. Function `effort_to_gemini_thinking(effort: str) -> dict | None`:
   - Maps to thinkingConfig budget tokens or thinkingLevel.
6. Helper `model_supports_reasoning(provider: str, model_id: str) -> bool`.
</action>
<verify>
Run unit tests in `tests/core/test_reasoning_effort.py` verifying clamping, Anthropic token translation, and Gemini config generation.
</verify>
<done>
All vocabulary sets, clamping algorithms, and translation helpers pass tests.
</done>
</task>

<task>
<name>2. Wire Reasoning Effort into Router, Config Loader, Onboard, and TUI</name>
<action>
1. In `src/harness_core/config_loader.py`:
   - Parse `reasoning_effort` under `model:` in `config.yaml` (default "medium" for reasoning models, "none" for non-reasoning).
   - Load `HEX_REASONING_EFFORT` from environment.
2. In `src/harness_core/router.py`:
   - In `_format_cloud_payload` / provider request builders:
     - For OpenAI: attach `"reasoning_effort": clamped_effort` if model is o1/o3-mini/gpt-5.6.
     - For Anthropic: attach `"thinking": effort_to_anthropic_thinking(effort)` if Claude 3.7.
     - For Gemini / Antigravity: attach `thinkingConfig` if Gemini 2.0/2.5 Thinking.
3. In `src/harness_core/onboard.py`:
   - After selecting `cloud_model_id`, call `model_supports_reasoning(provider, cloud_model_id)`.
   - If true, display reasoning effort picker (`low`, `medium`, `high`, `max`, `none`).
   - Write selected effort into `config.yaml` (`model.reasoning_effort`).
4. In `src/harness_core/tui.py`:
   - Add `/reasoning [level]` slash command to view or dynamically switch reasoning effort.
</action>
<verify>
Run `.venv/bin/python -m unittest tests/core/test_reasoning_effort.py` and verify router payload generation across Anthropic, OpenAI, and Gemini.
</verify>
<done>
Router correctly applies wire payloads and TUI command `/reasoning` updates active session configuration.
</done>
</task>
</tasks>
