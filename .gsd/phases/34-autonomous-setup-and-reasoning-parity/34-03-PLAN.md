# Plan 34.03: Setup Ergonomics, Curated Provider Tiers & First-Task Verification

<objective>
Elevate HEX setup ergonomics to match and exceed Hermes Agent. Implement `--quick`, `--blank-slate`, and `--reset` flags in `cli.py` and `onboard.py`, organize provider selection into 4 intuitive curated tiers, and add an automated First-Task verification beat that runs in an isolated CoW workspace.

Purpose: Eliminate decision fatigue, provide lightweight deployment profiles for CI/minimal runners, and deliver an immediate verification 'aha moment' on first install.
Output: Updated `onboard.py`, `cli.py`, and `tests/client/test_onboarding_ergonomics.py`.
</objective>

<tasks>
<task>
<name>1. Implement '--quick', '--blank-slate', '--reset', and Curated Provider Tiers</name>
<action>
1. In `src/harness_core/cli.py`:
   - Add `--quick`, `--blank-slate`, `--reset` arguments to `hex setup` / `hex onboard`.
2. In `src/harness_core/onboard.py`:
   - Implement `--quick` logic: If existing config/creds are valid for a section (e.g. model configured), skip prompting for that section and only prompt for unconfigured items (e.g., search engine or messaging).
   - Implement `--blank-slate` logic: Set minimal configuration (only essential tools, deterministic local compression, disabled telemetry/gateways, 90 turns ceiling).
   - Implement `--reset` logic: Prompt confirmation, archive or clear existing `.hex/` configuration, and restart wizard.
   - Refactor provider selection menu:
     Instead of flat 26-option list, present curated top-level categories:
       1. Recommended & Included (Antigravity IDE Included Quota, Anthropic Claude 3.7, OpenAI GPT-4o)
       2. Unified Gateways (OpenRouter, Vercel AI Gateway)
       3. Local Offline (Ollama, LM Studio, MLX Local)
       4. Enterprise Cloud & High-Speed (DeepSeek, Groq, Cerebras, Bedrock, Vertex, Azure)
       5. View All 26 Providers (Flat List)
</action>
<verify>
Run unit tests in `tests/client/test_onboarding_ergonomics.py` validating `--quick` skips configured sections, `--blank-slate` writes minimal configs, and tier navigation correctly resolves providers.
</verify>
<done>
Ergonomic flags and tiered provider selection function reliably.
</done>
</task>

<task>
<name>2. Implement Guided First-Task Verification Beat</name>
<action>
1. In `src/harness_core/onboard.py`:
   - At the end of onboarding, add an optional First-Task verification beat:
     `[y] Run system self-test & first-task verification (Recommended)`
   - When confirmed:
     a) Creates an isolated CoW workspace snapshot (`active_workspaces/ws_first_task`).
     b) Generates a test artifact in `~/hex-first-task/diagnostics.md` confirming compiler availability, CoW cloning, and CAS storage.
     c) Records task event in `ledger.db` with CAS SHA-256 hash.
     d) Prints clean green status table confirming the complete harness is operational.
2. In `tests/client/test_onboarding_ergonomics.py`:
   - Add test case verifying the first-task verification beat executes and produces expected ledger records and workspace artifacts.
</action>
<verify>
Run `.venv/bin/python -m unittest tests/client/test_onboarding_ergonomics.py`.
</verify>
<done>
First-task verification beat runs successfully in isolated CoW workspace and records proof in ledger.
</done>
</task>
</tasks>
