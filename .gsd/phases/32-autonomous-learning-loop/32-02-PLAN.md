# Plan 32.02: Autonomous Friction Sensor & Hardware-Gated Background Reflection

<objective>
Implement an autonomous friction sensor in `ReActLoop` and `HarnessOrchestrator` that detects multi-step friction and retry escalation ($\ge 3$ repair attempts), strictly gated by hardware profiling (`auto_reflect = "cloud_only" | "idle" | "off"`) to protect unified memory on local Apple Silicon and local inference runners, synthesizing actionable lessons into `.hex/reflections/LESSONS.md` wired into `MemoryLifecycleManager`.

Purpose: Enable closed-loop self-learning from debugging and repair struggles without user intervention, while safeguarding local machine resources against unified memory thrashing.
Output: `src/harness_core/reflection.py`, updated `react_loop.py`, `orchestrator.py`, `config_loader.py`, `memory.py`, and test suite in `tests/cognition/test_autonomous_learning.py`.
</objective>

  <name>Task 1: Autonomous Friction Sensor & Hardware Gating in ReActLoop and Orchestrator</name>
  <files>src/harness_core/config_loader.py, src/harness_core/react_loop.py, src/harness_core/orchestrator.py</files>
  <action>
    Enhance `src/harness_core/config_loader.py`, `src/harness_core/react_loop.py`, and `src/harness_core/orchestrator.py`:
    1. Hardware Gating Configuration in `src/harness_core/config_loader.py`:
       - Parse `learning.auto_reflect` from `config.yaml` with options: `"cloud_only"` (default), `"idle"`, `"off"`.
       - Map to environment variable `HEX_AUTO_REFLECT`.
       - Helper `get_auto_reflect_policy(workspace_root=None) -> str`: returns active reflection mode.
       - Helper `should_execute_background_reflection(policy: str, router=None, is_idle: bool = False) -> tuple[bool, str]`:
         - If `policy == "off"`: returns `(False, "Autonomous reflection disabled (policy=off)")`.
         - If `policy == "cloud_only"`: inspects active model router provider. If the active provider is local (MLX, Ollama, local vLLM, CPU/Metal) or running on Apple Silicon unified memory without cloud routing, returns `(False, "Suppressed background reflection on local hardware to prevent memory starvation")`. If routed to a cloud model (Anthropic, OpenAI, Gemini), returns `(True, "Cloud-routed reasoner active")`.
         - If `policy == "idle"`: returns `(True, "Executing during idle")` only if `is_idle` is True, else defers.
    2. Friction Detection in `ReActLoop`:
       - Track turn-level repair attempts and multi-step friction (`turn_repair_count`, consecutive tool errors, compiler errors).
       - Maintain `friction_detected: bool = False` flag when:
         - `retry_count >= 3` or `repair_attempts >= 3`, OR
         - Same tool failed >= 2 times with identical error before succeeding, OR
         - LSP compiler preflight encountered multiple fatal errors before a valid patch succeeded.
       - Emit `friction_event` through `_emit_event("friction_detected", {...})`.
       - Expose `friction_info: dict[str, Any]` on `ReActSessionResult`.
    3. Orchestrator Integration in `HarnessOrchestrator`:
       - In `_execute_standard_dag` and `run_agent_loop`: when a task succeeds after `repair_attempt >= 3` or `result.friction_info` indicates friction, trigger reflection evaluation.
       - Check `should_execute_background_reflection`:
         - If allowed: dispatch reflection synthesis in `ReflectionSynthesizer`.
         - If suppressed (e.g. `cloud_only` on local M-series hardware): log reflection candidate to `.hex/reflections/pending_reflections.json` for later offline processing without blocking or stalling active inference.
    AVOID: Unconditionally spawning background subagents or LLM calls on local Apple Silicon / Ollama instances without checking hardware gating.
  </action>
  <verify>.venv/bin/pytest tests/cognition/test_autonomous_learning.py -k "test_hardware_gating or test_friction_sensor" -v</verify>
  <done>ReActLoop and Orchestrator detect >= 3 repair friction; config_loader evaluates auto_reflect policy; local hardware runs suppress background subagents to protect unified memory.</done>
</task>

       - Check promotions: when a reflection achieves `hit_counter >= 3`, trigger promotion to `MEMORY.md` or flag for `SKILL.md` compilation via `SkillCompiler`.
    AVOID: Generating verbose, unstructured paragraphs; enforce concise, machine-readable post-mortem summaries with clear [AVOID] invariants.
