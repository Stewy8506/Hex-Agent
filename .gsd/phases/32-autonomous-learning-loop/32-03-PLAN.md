  <name>Task 1: Cross-Session FTS5 + Graphify AST Hybrid Retrieval Engine</name>
  <files>src/harness_core/skills/retrieval.py, src/harness_core/skills/__init__.py</files>
  <action>
    Create `src/harness_core/skills/retrieval.py` implementing:
    1. Data Models:
       - `RetrievalMatch`:
         - `item_type: str` ("skill" | "lesson" | "memory")
         - `identifier: str`
         - `title: str`
         - `content: str`
         - `score: float`
         - `match_type: str` ("lexical_fts5" | "ast_1hop" | "hybrid")
         - `source_file: str | None = None`
         - `associated_symbols: list[str] = field(default_factory=list)`
    2. `HybridLearningRetriever`:
       - `__init__(ledger: LedgerStore, graphify: ActiveGraphifyAdapter | None = None, workspace_root=None, global_home=None)`:
         - Initializes access to SQLite ledger (with FTS5 tables), active Graphify index, local `.hex/skills/`, and global `~/.hex/skills/`.
       - `query(query_text: str, target_file_or_symbol: str | None = None, limit: int = 10) -> list[RetrievalMatch]`:
         - Step 1 (Lexical FTS5 Retrieval): Queries SQLite FTS5 across skills, task journals, transcripts, and archived memories. Scores matches using BM25 ranking.
         - Step 2 (AST 1-Hop Traversal): If `target_file_or_symbol` is provided or symbols are detected in `query_text`, queries Graphify to find:
           - Defining file and symbol node.
           - 1-hop callers and 1-hop callees.
           - Finds lessons and skills that cite any node in this 1-hop neighborhood.
         - Step 3 (Score Fusion & Re-Ranking): Combines lexical BM25 scores with structural AST proximity (assigning proximity boost for 1-hop matches). Deduplicates results and returns top-K ranked `RetrievalMatch` objects.
       - `find_skills_for_task(goal: str, target_files: list[str] | None = None) -> list[RetrievalMatch]`:
         - Specialized query to retrieve relevant reusable skills during task intake or planning.
    3. Expose retrieval API in `src/harness_core/skills/__init__.py`.
    AVOID: Relying solely on keyword substring checks without FTS5 BM25 ranking; avoid ignoring AST caller/callee relations when code symbols are mentioned.
  </action>
  <verify>.venv/bin/pytest tests/cognition/test_autonomous_learning.py -k "test_hybrid_retrieval" -v</verify>
  <done>HybridLearningRetriever combines FTS5 lexical BM25 search with Active Graphify 1-hop caller/callee traversal, returning ranked skills and lessons.</done>
