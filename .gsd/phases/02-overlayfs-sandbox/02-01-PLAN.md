<task type="auto">
  <name>Implement OverlayFSSnapshotProvider, BtrfsSnapshotProvider, and provider factory</name>
  <files>src/harness_core/cow.py, src/harness_core/orchestrator.py</files>
  <action>
    Enhance `src/harness_core/cow.py` with Linux CoW backends and platform auto-detection:
    1. Implement `OverlayFSSnapshotProvider` conforming to `WorkspaceSnapshotProvider`:
       - `backend_name = "linux_overlayfs"` (or `"fuse_overlayfs"` if using fuse-overlayfs).
       - Maintain directory layout under `snapshots_root`:
         - Snapshots store immutable base trees (`lowerdir`).
         - Active workspaces store layered structures: `upperdir` (read-write delta), `workdir` (internal scratch), and `merged` (the unified mount point).
       - Probe support via `_probe_overlayfs()`: check kernel overlayfs with user namespaces (`unshare -m -U`), `fuse-overlayfs` binary, or root mount permissions.
       - `create_snapshot(source_dir, label)`:
         - Creates snapshot directory under `snapshots_root / snap_id` as the immutable lower layer.
         - Computes deterministic SHA-256 Merkle tree SHA using `compute_tree_sha()`.
         - Returns `SnapshotMetadata`.
       - `clone_to_workspace(snapshot_path, target_dir)`:
         - Configures `snapshot_path` as `lowerdir`.
         - Allocates unique `upperdir` and `workdir` directories.
         - Mounts overlay onto `target_dir` (using `fuse-overlayfs`, unprivileged user namespace mount, or mount command).
         - Returns `compute_tree_sha(target_dir)`.
       - `rollback_workspace(workspace_dir, snapshot_path)`:
         - Rapid CoW revert: unmounts overlay, purges `upperdir` and `workdir`, recreates clean empty layer directories, and remounts.
         - Preserves `.git` directory if git tracking exists.
         - Returns `compute_tree_sha(workspace_dir)`.
       - `export_delta_archive(snapshot_path, archive_dest)`:
         - Packs snapshot or layer delta into a deterministic `.tar.gz` CAS bundle.
       - `discard_snapshot(snapshot_path)`:
         - Safely unmounts if mounted and removes associated directories without leaking mount points.
       - Register an `atexit` unmount cleanup handler to prevent dangling FUSE or namespace mounts on process exit.
    2. Implement `BtrfsSnapshotProvider`:
       - `backend_name = "btrfs_subvolume"`.
       - Detects if `snapshots_root` is on Btrfs filesystem via `_probe_btrfs()`.
       - Uses `btrfs subvolume snapshot -r` for read-only snapshots and `btrfs subvolume snapshot` for writable workspace branches.
       - Rollback cleanly replaces subvolume with a fresh snapshot.
    3. Implement factory function `get_default_snapshot_provider(root_dir: Path | str) -> WorkspaceSnapshotProvider`:
       - If `platform.system() == "Darwin"` and APFS clone succeeds: return `APFSAndPortableCoWProvider(root_dir)`.
       - If `platform.system() == "Linux"`:
         - If Btrfs detected: return `BtrfsSnapshotProvider(root_dir)`.
         - If OverlayFS / fuse-overlayfs detected: return `OverlayFSSnapshotProvider(root_dir)`.
         - Otherwise return `APFSAndPortableCoWProvider(root_dir)` (portable copy backend).
       - Fallback for other platforms: return `APFSAndPortableCoWProvider(root_dir)`.
    4. In `src/harness_core/orchestrator.py`:
       - Allow passing `cow: WorkspaceSnapshotProvider | None = None` to `HarnessOrchestrator.__init__`.
       - Default `self.cow = cow or get_default_snapshot_provider(self.data_dir / "cow_snapshots")`.
    AVOID: Leaving zombie mount points or attempting destructive `rmtree` on an active mount without unmounting first.
  </action>
