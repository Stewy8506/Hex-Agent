# Plan 13.01: Interactive Terminal Selector, Environment Hydration & Autonomous Web Search

<objective>
Implement core interaction and agent capabilities:
1. Terminal UI selector (`src/harness_core/ui_selector.py`) featuring interactive arrow-key selection (`[•]` / `[ ]`), clean ANSI row refreshes, and masked API key inputs.
2. Real-time configuration & credentials loader (`src/harness_core/config_loader.py`) ensuring `~/.hex/credentials.env` and `~/.hex/config.yaml` are loaded into `os.environ` on every CLI invocation.
3. Autonomous Web Search Tool (`src/harness_core/web_search.py`) with zero-key DuckDuckGo fallback and API key support (Tavily/Brave), registered in `ToolGateway` (`src/harness_core/gateway.py`).
4. Unit and integration test suite (`tests/test_ui_selector_and_web_search.py`).
</objective>

<tasks>

2. Author `src/harness_core/config_loader.py` with `load_hex_environment()` and wire into `cli.py:main()`.
3. Author `src/harness_core/web_search.py`, wire `_tool_web_search` into `src/harness_core/gateway.py`, and author unit tests in `tests/test_ui_selector_and_web_search.py`.
</tasks>
