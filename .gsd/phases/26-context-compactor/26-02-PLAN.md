# Plan 26.02: Middle-Turn Summarizer & Immutable Prompt-Cache Prefixing

<objective>
Implement Phases 3 & 4 of the context compactor in `src/harness_core/context_compressor.py` and wire it into the workbench runtime (`ReActLoop`, `TwoTierModelRouter`, `HarnessOrchestrator`, and `HexConsole` TUI). This delivers the middle-turn summarizer (compacting bloated conversational turns between the protected system head and active tail with model-driven or deterministic fallback summaries, and restating in-flight tasks) and immutable prompt-cache prefixing (locking static system instructions, tool schemas, and provider cache breakpoints for >90% KV prompt cache hit rate across Anthropic, Gemini, and OpenAI).

Purpose: Enable indefinite multi-turn autonomous coding sessions that stay strictly within context limits while minimizing API costs and latency via high prompt-cache hit rates.

  <action>
    Implement Phase 3 Middle-Turn Summarization and the full `ContextCompactor` class in `src/harness_core/context_compressor.py`:
    1. Define configuration and telemetry dataclasses:
       - `CompactionConfig`: `max_context_tokens: int = 100_000`, `trigger_threshold: float = 0.8`, `protect_first_n: int = 1`, `protect_last_n: int = 6`, `tail_token_budget: int = 25_000`, `keep_tool_rounds: int = 4`, `min_demote_chars: int = 1000`.
       - `CompactionResult`: `compacted_messages: list[dict]`, `original_tokens: int`, `compacted_tokens: int`, `compression_ratio: float`, `phase1_demoted_tools: int`, `phase3_summarized_turns: int`, `used_fallback: bool`.
    2. Implement compaction window determination (`_plan_compaction_window`):
       - `protect_head_size`: system message (index 0) + decaying `protect_first_n` (decays to 0 once compressed so initial turns do not fossilize, unless pinned).
       - `compress_start`: aligned forward using `align_boundary_forward` from Plan 26.01.
       - `compress_end`: calculated backward from tail by token budget (`tail_token_budget`) and turn count (`protect_last_n`), aligned using `align_boundary_backward`.
    3. Implement Middle-Turn Summarization:
       - Model-assisted summarizer: If `model_caller` is configured, invoke it with structured prompt requesting:
         - `## CONTEXT COMPACTION SUMMARY`
         - `### Active Goals & User Intent`
         - `### Actions Taken & Files Modified`
         - `### Key Findings, Errors & Tool Results`
         - `### Current Working State`
         - Delimited with `--- END OF CONTEXT SUMMARY ---`
       - Deterministic fallback summarizer: If model call fails, times out, returns refusal, or is omitted, deterministically parse middle turns into a clean markdown digest extracting user prompts, tool names/arguments, and exit statuses.
       - In-flight task restatement (`_INFLIGHT_TASK_REPLAY_HEADER`): If the latest user request is enclosed within the compacted region, append a restatement turn after the summary delimiter so active work is not abandoned.
    4. Implement anti-thrashing and safety checks:
       - If compacted transcript has more tokens than original (`compacted_tokens >= original_tokens`), reject compaction and return original messages.
    AVOID: Allowing early user turns to fossilize permanently across successive compactions; decay `protect_first_n` after the first compaction run.

<task type="auto">
  <name>Task 2: Immutable Prompt-Cache Prefixing & Provider Cache Breakpoints</name>
  <files>src/harness_core/context_compressor.py</files>
  <action>
    Implement Phase 4 Immutable Prompt-Cache Prefixing and Cache Breakpoint utilities in `src/harness_core/context_compressor.py`:
    1. Implement prompt cache stabilization:
       - `stabilize_prompt_cache_prefix(messages: list[dict[str, Any]], system_prompt: str, tools_schema: list[dict[str, Any]] | None = None) -> list[dict[str, Any]]`:
         - Enforce that `system` message always occupies index 0 with canonical, bit-for-bit identical text.
         - Guarantee tool schemas are deterministically serialized with sorted keys to avoid hash churn.
         - Ensure dynamic runtime stamps (e.g. current datetime, ephemeral warnings) are placed in a downstream turn or non-cached carrier, NEVER in the static system prefix.
    2. Implement provider-specific cache breakpoints:
       - `apply_cache_control_breakpoints(messages: list[dict[str, Any]], tools: list[dict[str, Any]] | None = None, provider: str = 'anthropic') -> tuple[list[dict[str, Any]], list[dict[str, Any]] | None]`:
         - For Anthropic: Inject `"cache_control": {"type": "ephemeral"}` onto:
           1. The last tool definition in `tools` (caches tools schema).
           2. The system prompt message (caches static system instructions).
           3. The latest context summary checkpoint in middle history (caches historical session).
           4. The second-to-last turn in the active tail (caches conversation prefix for next generation).
           Respect Anthropic maximum of 4 cache breakpoints per request.
         - For Gemini and OpenAI: Ensure messages maintain exact prefix byte stability without modifying structure.
    3. Implement cache fingerprinting and verification:
       - `compute_cache_signature(messages: list[dict[str, Any]], tools: list[dict[str, Any]] | None = None, prefix_turns: int = 2) -> str`: Returns SHA-256 hex digest of the static prefix. Verify that across turns, the prefix signature remains 100% constant to guarantee >90% KV cache hit rate.
    AVOID: Altering or re-ordering tool definitions, or inserting varying timestamps into the system prompt across turns, as even a 1-character shift invalidates the entire downstream KV cache.
  </action>
  <verify>
    .venv/bin/python -c "from harness_core.context_compressor import stabilize_prompt_cache_prefix, apply_cache_control_breakpoints, compute_cache_signature; msgs = [{'role': 'user', 'content': 'q1'}, {'role': 'assistant', 'content': 'a1'}]; tools = [{'name': 'read_file', 'description': 'read'}]; p_msgs = stabilize_prompt_cache_prefix(msgs, 'Sys instructions', tools); sig1 = compute_cache_signature(p_msgs, tools); p_msgs2 = stabilize_prompt_cache_prefix(msgs + [{'role': 'user', 'content': 'q2'}], 'Sys instructions', tools); sig2 = compute_cache_signature(p_msgs2, tools); assert sig1 == sig2, 'Cache prefix signature drifted!'; tagged_msgs, tagged_tools = apply_cache_control_breakpoints(p_msgs, tools, provider='anthropic'); assert tagged_tools[-1].get('cache_control') == {'type': 'ephemeral'}; print('Phase 4 Prompt-Cache Prefixing verified')"
  </verify>
  <done>
    `stabilize_prompt_cache_prefix` and `apply_cache_control_breakpoints` guarantee byte-for-byte prefix stability and correct Anthropic cache_control breakpoints.
  </done>
