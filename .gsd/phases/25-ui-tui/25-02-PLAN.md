### Context & Requirements
- Modular Components in `ui-tui/src/components/`:
  - `MessageRow.tsx`: User prompt & assistant response with syntax styling.
  - `ToolCallBadge.tsx`: Collapsible status badge showing running/completed tool calls with execution duration and arguments.
  - `DiffViewer.tsx`: Side-by-side / unified colorized patch diff preview.
  - `StatusBar.tsx`: Model ID, CoW snapshot mode, active token counts, and voice/ReAct badges.
  - `ApprovalCard.tsx`: One-key `[y] Approve`, `[n] Reject`, `[d] Diff` approval dialog.
  - `Composer.tsx`: Input box with history cycling, multi-line support, and slash-command autocompletion.
- Optimizations:
  - 30ms streaming throttler in `ui-tui/src/lib/throttle.ts` preventing terminal cursor jitter during fast token emission.
  - Transcript virtualization in `ui-tui/src/components/Transcript.tsx`: settled historical turns rendered as memoized static strings to bypass Ink Yoga flexbox layout passes.
- Python Integration:
  - Add `hex tui` and `hex chat --ink` in `src/harness_core/cli.py` to spawn the bundled Node.js app pointing to `hex acp`.
