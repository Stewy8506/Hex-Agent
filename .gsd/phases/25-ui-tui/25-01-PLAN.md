# Plan 25-01: `ui-tui` Workspace Scaffolding, ACP/JSON-RPC Bridge & Nano Stores

**Phase:** Phase 25 — Modular React + Ink Terminal UI (`ui-tui`) (Hermes Parity Pillar 2)  
**Task:** 25-01  
**Wave:** 1  
**Objective:** Scaffold the TypeScript React 19 + Ink package in `ui-tui/` with high-performance Nano Stores state management, `esbuild` fast bundler, and a robust JSON-RPC 2.0 stdio client connecting to HEX's native ACP engine (`src/harness_core/acp.py`).

---

### Context & Requirements
- Drawing directly from `/tmp/hermes-agent/ui-tui/`:
  - `package.json` with dependencies: `react` (19.x), `ink` (5.x or 6.x), `@nanostores/react`, `nanostores`, `ink-text-input`, `chalk`.
  - `tsconfig.json` configured for modern ESM (`NodeNext` / `ESNext`) and React JSX.
  - `src/domain/store.ts`: Nano Stores atoms and maps (`$session`, `$messages`, `$activeToolCalls`, `$status`, `$theme`) to ensure fine-grained reactive updates without parent component re-renders.
  - `src/gatewayClient.ts`: Bidirectional JSON-RPC 2.0 stdio client that spawns `hex acp` or connects to an existing stdio stream, implementing methods: `initialize`, `session/new`, `session/prompt`, `session/cancel`, `tools/list`, and `tools/call`.
  - Build script in `scripts/build.mjs` using `esbuild` for $<50\text{ ms}$ bundling.

---

### Proposed Implementation Tasks
1. Initialize `ui-tui/` directory:
   - Create `ui-tui/package.json` and `ui-tui/tsconfig.json`.
   - Install dependencies.
2. Build `ui-tui/src/domain/store.ts` with Nano Stores:
   - Atomic state stores for connection status, message transcript, running tool calls, approval cards, and status bar metrics.
3. Build `ui-tui/src/gatewayClient.ts`:
   - JSON-RPC 2.0 stdio / socket client talking to HEX's ACP server.
4. Author verification test script:
   - `ui-tui/src/__tests__/client.test.ts` or standalone Node test verifying client handshake with `hex acp`.
