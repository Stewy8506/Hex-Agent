# Plan 06.01: WorkerDaemon Architecture, Heartbeat Loop, Server API & CLI `harness worker`

<objective>
Implement the distributed `WorkerDaemon` architecture in `src/harness_core/worker_daemon.py`, the lease renewal and worker heartbeat endpoints in `src/harness_core/server.py` and `src/harness_core/db.py`, and the `harness worker` CLI command in `src/harness_core/cli.py`. The worker daemon runs as an autonomous agent on heterogeneous machines (MacBook Air M4, Desktop GPU, Server), detects hardware capabilities and local models, maintains an active heartbeat thread renewing leases (`expires_at = now + lease_ttl`), claims tasks atomically from the control plane using either in-process direct ledger access or authenticated HTTP REST transport (`X-Worker-Token`), and gracefully handles termination signals (`SIGTERM`, `SIGINT`) by cleanly releasing active leases. Prove full functionality with a comprehensive test suite in `tests/test_worker_daemon.py`.

Purpose: Enable tasks to be dispatched and claimed across isolated worker nodes with reliable lease heartbeats, atomic CAS fencing, and resilient transport options.
Output: Core `WorkerDaemon` implementation, REST API worker routes, `harness worker` CLI command, and `tests/test_worker_daemon.py`.
</objective>

       - `renew_lease(self, lease_id: str, fencing_token: int, ttl_seconds: int = 300) -> dict[str, Any]` (and `renew_lease_async`):
         - Verifies lease exists and `released_at IS NULL`.
         - Validates fencing token: queries active task's `COALESCE(MAX(fencing_token), 0)`. If `fencing_token < max_tok`, raises `ConcurrencyFenceError`.
         - Computes new expiration `expires = (now + timedelta(seconds=ttl_seconds)).isoformat()`.
         - Updates `leases SET expires_at = ?, renewed_at = ? WHERE lease_id = ? AND released_at IS NULL`.
         - Updates `workers.last_heartbeat_at = now` for the associated `worker_id`.
         - Returns updated lease dict.
       - `release_lease(self, lease_id: str, fencing_token: int | None = None) -> dict[str, Any]` (and `release_lease_async`):
         - Updates `leases SET released_at = ? WHERE lease_id = ? AND released_at IS NULL`.
         - Returns updated lease dict.
       - `heartbeat_worker(self, worker_id: str, health: str = "HEALTHY") -> dict[str, Any]` (and `heartbeat_worker_async`):
         - Updates `workers SET last_heartbeat_at = ?, health = ? WHERE worker_id = ?`.
         - Returns updated worker dict.
    2. In `src/harness_core/server.py`, add worker-facing REST API routes to `HarnessAPIApp.handle_request`:
       - Authentication check: Support optional `auth_token: str | None` in `HarnessAPIApp.__init__`. If invalid or missing on worker/task mutating endpoints, return `(HTTPStatus.UNAUTHORIZED, {"error": "Unauthorized worker token"}, "application/json")`.
       - `POST /v1/workers/register`: Accepts `worker_id`, `machine_class`, `cow_backend`, `capabilities`, `local_llm_models`, `trust_level`. Calls `self.orch.ledger.register_worker(...)` and returns `200 OK` with worker record.
       - `POST /v1/workers/heartbeat`: Accepts `worker_id`, `health`. Calls `self.orch.ledger.heartbeat_worker(...)` and returns `200 OK`.
       - `POST /v1/tasks/claim`: Accepts `worker_id`, `ttl_seconds`. Calls `self.orch.ledger.claim_next_task(worker_id=worker_id, ttl_seconds=ttl_seconds)`. If claimed, returns `200 OK` with claimed task payload; if queue empty, returns `200 OK` with `{"task": None}`.
       - `POST /v1/leases/{lease_id}:renew`: Accepts `fencing_token`, `ttl_seconds`. Calls `self.orch.ledger.renew_lease(...)` and returns `200 OK`.
       - `POST /v1/leases/{lease_id}:release`: Accepts `fencing_token`. Calls `self.orch.ledger.release_lease(...)` and returns `200 OK`.
       - Error mapping: In `handle_request` exception handling, explicitly catch `ConcurrencyFenceError` and return `(HTTPStatus.CONFLICT, {"error": "ConcurrencyFenceError", "detail": str(exc)}, "application/json")` (HTTP 409 Conflict).

<task type="auto">
  <name>Implement WorkerDaemon Architecture and harness worker CLI Command</name>
  <files>src/harness_core/worker_daemon.py, src/harness_core/cli.py</files>
  <action>
    Create `src/harness_core/worker_daemon.py` and wire the CLI subcommand in `src/harness_core/cli.py`:
    1. In `src/harness_core/worker_daemon.py`:
       - Define `WorkerClient` protocol and two concrete implementations:
         - `DirectLedgerWorkerClient`: Wraps `LedgerStore` and `HarnessOrchestrator` directly for in-process local execution.
         - `RestWorkerClient`: Connects to `server_url` using standard library `urllib.request`. Attaches `X-Worker-Token: <token>`. Translates HTTP 409 to `ConcurrencyFenceError` and HTTP 401 to `PermissionError`.
         - Both provide unified methods: `register_worker`, `heartbeat`, `claim_task`, `renew_lease`, `release_lease`, `transition_task`, and `get_task`.
       - Hardware & Environment Profiling:
         - Implement `inspect_machine_profile(override_class: str | None = None) -> dict[str, Any]`:
           - Detects `machine_class`: "m4_air" (if Darwin and ARM64 / Apple Silicon), "desktop_gpu" (if Linux/CUDA or Darwin with high core/RAM count), or "server". Honors `override_class` if provided and not "auto".
           - Detects `cow_backend`: uses `get_default_snapshot_provider().backend_name`.
           - Detects `capabilities`: CPU cores (`os.cpu_count()`), memory (via psutil or platform sysctl/meminfo fallback), OS name/release, Python version.
           - Detects `local_llm_models`: queries local MLX cache or supported model names.
           - Sets default `trust_level`: "trusted_local".
       - Implement `WorkerDaemon`:
         - `__init__(self, client: WorkerClient, worker_id: str | None = None, machine_class: str = "auto", poll_interval: float = 2.0, lease_ttl: int = 300, orchestrator: HarnessOrchestrator | None = None)`:
           - Generates stable `worker_id` (e.g. `f"worker-{socket.gethostname()}-{uuid.uuid4().hex[:6]}"`) if not provided.
           - Inspects hardware profile and stores capabilities.
           - Creates `threading.Event()` for `_stop_event`.
           - Tracks `current_task_id`, `current_lease_id`, `current_fencing_token`.
         - `start(self)`: Registers worker with control plane, starts background heartbeat thread `_heartbeat_loop`, and enters task claim loop `_claim_loop`.
         - `_heartbeat_loop(self)`:
           - Runs every `max(1.0, lease_ttl / 3.0)` seconds while `not _stop_event.is_set()`.
           - Calls `client.heartbeat(worker_id)`.
           - If `current_lease_id` and `current_fencing_token` are active: calls `client.renew_lease(current_lease_id, current_fencing_token, ttl_seconds=lease_ttl)`.
           - If `renew_lease` raises `ConcurrencyFenceError`, logs warning, sets `fenced = True`, and triggers task preemption.
         - `_claim_loop(self, once: bool = False)`:
           - While `not _stop_event.is_set()`:
             - Calls `client.claim_task(worker_id, ttl_seconds=lease_ttl)`.
             - If task claimed:
               - Sets `current_task_id`, `current_lease_id`, `current_fencing_token`.
               - Executes task: invokes `self.orchestrator.execute_task(task_id, worker_id=self.worker_id)` (or runs steps via client).
               - Clears `current_task_id`, `current_lease_id`, `current_fencing_token`.
               - If `once`: breaks loop and exits cleanly.
             - If no task: waits on `_stop_event.wait(timeout=poll_interval)`.
         - Graceful Termination:
           - Implement `stop(self)`:
             - Sets `_stop_event`.
             - If `current_lease_id` and `current_fencing_token` are set, calls `client.release_lease(current_lease_id, current_fencing_token)` so other workers can immediately pick up.
             - Joins heartbeat thread.
           - Setup signal handlers for `SIGTERM` and `SIGINT` to call `stop()`.
    2. In `src/harness_core/cli.py`:
       - Add `worker` parser:
         `p_wrk = sub.add_parser("worker", help="Start standalone distributed worker daemon")`
         `p_wrk.add_argument("--worker-id", default=None, help="Worker ID (defaults to hostname-hash)")`
         `p_wrk.add_argument("--machine-class", choices=["auto", "m4_air", "desktop_gpu", "server"], default="auto")`
         `p_wrk.add_argument("--poll-interval", type=float, default=2.0, help="Task queue poll interval in seconds")`
         `p_wrk.add_argument("--lease-ttl", type=int, default=300, help="Lease TTL in seconds")`
         `p_wrk.add_argument("--server-url", default=None, help="Control plane HTTP URL. If omitted, uses local direct ledger")`
         `p_wrk.add_argument("--token", default=None, help="Worker authentication token")`
         `p_wrk.add_argument("--once", action="store_true", help="Execute at most one claimed task and exit")`
       - In `main()` handler for `args.cmd == "worker"`:
         - If `args.server_url`: construct `RestWorkerClient(args.server_url, token=args.token)`.
         - Else: construct `DirectLedgerWorkerClient(orch)`.
         - Instantiate `WorkerDaemon(...)` and invoke `daemon.run(once=args.once)`.
  </action>
