# Plan 19-01: NVIDIA SkillSpector Python AST & Behavioral Dangerous Code Integration

**Phase:** Phase 19 (NVIDIA SkillSpector Upstream Behavioral AST & Live OSV Scanner)  
**Plan:** 19-01  
**Status:** In Progress  
**Objective:** Replace shallow regex scanning of bundled `.py` skill scripts with upstream NVIDIA SkillSpector's `skillspector.python_ast` and `skillspector.nodes.analyzers.behavioral_ast` dangerous call and taint tracking engine.

---

## Tasks

### Task 1: Wire Upstream Behavioral AST Analyzer into `SkillSpectorScanner`
- **Files to Modify:** `src/harness_core/skillspector.py`
- **Action:**
  - Import `get_python_ast` from `skillspector.python_ast` and `_analyze_python` from `skillspector.nodes.analyzers.behavioral_ast`.
  - In `SkillSpectorScanner.scan_bundle()`, when iterating over files in the skill bundle, if a file ends with `.py`:
    - Invoke `get_python_ast(None, content, rel)` to parse AST with alias resolution and source location tracking.
    - Run `_analyze_python(parsed_ast, rel)` to extract behavioral AST findings (AST1 through AST12: dangerous builtins, subprocess execution, dynamic imports, insecure deserialization, reflective `getattr` execution, and `__subclasses__` gadget chains).
    - Map each finding into `matched_rules` with severity mapping (`CRITICAL` -> score 95, `HIGH` -> score 80, `MEDIUM` -> score 55, `LOW` -> score 25), file path, line numbers, and exact code snippet context.
  - Retain clean zero-dependency fallback if upstream import fails.
- **Verification:** AST findings populate `matched_rules` and elevate `max_score` / `risk_score` to trigger automatic quarantine (`REJECT_QUARANTINE`).

### Task 2: Author Behavioral AST Test Suite
- **Files to Create:** `tests/test_skillspector_ast_wiring.py`
- **Action:**
  - Create test cases verifying:
    1. Detection of `eval()` and `exec()` (AST2) elevating risk score to $\ge 80$.
    2. Detection of `os.system()` and `subprocess.Popen()` (AST5).
    3. Detection of insecure deserialization `pickle.loads()` (AST10).
    4. Detection of dynamic import `importlib.import_module()`.
    5. Detection of reflective execution via `getattr(os, "system")` (AST9).
    6. Benign Python script passing with low risk score (`ALLOW`).
- **Verification:** `.venv/bin/python -m unittest tests/test_skillspector_ast_wiring.py` passes 6/6 tests.
