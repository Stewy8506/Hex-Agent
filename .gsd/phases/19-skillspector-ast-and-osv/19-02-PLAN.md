# Plan 19-02: Live OSV.dev Batch Vulnerability Scanner & Offline Cache Integration

**Phase:** Phase 19 (NVIDIA SkillSpector Upstream Behavioral AST & Live OSV Scanner)  
**Plan:** 19-02  
**Status:** In Progress  
**Objective:** Replace hardcoded 5-package OSV dictionary with upstream NVIDIA SkillSpector's `skillspector.nodes.analyzers.osv_client.query_batch()` engine, querying real-time CVE advisories from OSV.dev with offline local caching and graceful fallback.

---

## Tasks

### Task 1: Wire Upstream `osv_client.query_batch()` into Manifest Scanning
- **Files to Modify:** `src/harness_core/skillspector.py`
- **Action:**
  - Import `query_batch`, `OsvQueryBudget`, and `VulnResult` from `skillspector.nodes.analyzers.osv_client`.
  - In `SkillSpectorScanner.scan_bundle()`:
    - Parse package declarations from `requirements.txt`, `package.json`, and `SKILL.md` frontmatter/body into `(name, version)` pairs.
    - Call `osv_client.query_batch(packages, ecosystem="PyPI", timeout_seconds=5.0)` for Python dependencies, and `ecosystem="npm"` for Node/JS dependencies.
    - Extract discovered vulnerabilities (`vuln_id`, `severity`, `summary`) and add to `osv_vulns`.
    - If `severity` is `CRITICAL`, elevate score to 90+ (`QUARANTINE`); if `HIGH`, elevate score to 75+.
  - Integrate offline fallback to `KNOWN_OSV_VULNS` if network is unreachable, air-gapped, or times out.
- **Verification:** Bundles with vulnerable dependencies (e.g. `pyyaml==5.3`) trigger real CVE matches (`GHSA-6757-jp84-gxfx`, `PYSEC-2020-96`) and quarantine.

### Task 2: Author OSV Live & Offline Fallback Test Suite
- **Files to Create:** `tests/test_skillspector_osv_wiring.py`
- **Action:**
  - Create test cases verifying:
    1. Real or mocked OSV batch query detecting known CVEs in `requirements.txt`.
    2. Severity score escalation: Critical CVEs push risk score $\ge 85$ resulting in quarantine.
    3. Offline network failure fallback to local static `KNOWN_OSV_VULNS` database when API is mocked to timeout.
    4. Clean bundle with non-vulnerable dependencies passing with 0 CVE findings.
- **Verification:** `.venv/bin/python -m unittest tests/test_skillspector_osv_wiring.py` passes 4/4 tests.
