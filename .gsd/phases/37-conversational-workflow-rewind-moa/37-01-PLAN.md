# Plan 37-01: Conversational Timeline Rewind & Asynchronous Title Synthesis

<objective>
Implement conversational timeline rewinding (`/rewind <turn_id | -N>`) with historical branching in the SQLite ledger and execution state recovery, alongside an asynchronous background LLM title synthesis worker that derives concise 3-5 word session titles updating `tasks.goal` and the live Start screen resume list.
</objective>

<name>1. Implement Conversational Timeline Rewind Engine with Ledger Branching</name>
<files>
src/harness_core/storage/timeline_rewind.py
src/harness_core/storage/db.py
src/harness_core/storage/__init__.py
src/harness_core/core/react_loop.py

tests/test_timeline_rewind.py
</files>
<action>
1. Create `src/harness_core/storage/timeline_rewind.py` defining:
   - `RewindTarget`: Data model representing the rollback target (turn index, target event id, branch id).
   - `RewindResult`: Summary containing `target_turn`, `turns_rewound`, `branch_id`, `live_messages`, and `reverted_tool_count`.
   - `TimelineRewindManager`:
     - `rewind(task_id: str, target: int | str, messages: list[dict[str, Any]]) -> RewindResult`: Resolves `-N` relative offsets or absolute turn IDs.
     - Splits dialogue history at `target_turn`: retains active prefix `messages[:target_idx]`.
     - Soft-branches discarded turns: marks trailing turns with `is_active = 0` and archives them under a unique `branch_id` (e.g. `br_rewind_<uuid>`), recording a cryptographically hash-chained `TIMELINE_REWOUND` event in `task_events`.
     - Reverts uncommitted tool executions or dirty step records corresponding to the truncated turns in `LedgerStore`.
2. Enhance `LedgerStore` in `src/harness_core/storage/db.py`:
   - Add schema support for dialogue turn tracking if not present, or leverage `task_events` / `step_id` metadata.
   - Implement `record_timeline_branch(task_id: str, branch_id: str, superseded_turns: list[dict], reason: str)` and `get_active_dialogue(task_id: str)`.
   - Ensure foreign keys and hash chaining remain intact across branches.
3. Wire `/rewind` into `ReActLoop` (`src/harness_core/core/react_loop.py`) and `HexConsole` (`src/harness_core/client/tui.py`):
   - Add `ReActLoop.rewind_to(turn_spec: int | str) -> list[dict]`.
   - In `HexConsole.handle_slash_command`: handle `/rewind [turn_id | -N]` (default `-1`), invoke `TimelineRewindManager`, truncate active dialogue buffer, and render confirmation notice.
4. Export `TimelineRewindManager` in `src/harness_core/storage/__init__.py`.
5. Author comprehensive unit and integration tests in `tests/test_timeline_rewind.py` covering:
   - Relative rewind (`/rewind -1`, `/rewind -2`).
   - Absolute turn index rewind (`/rewind 3`).
   - Boundary clamping (rewinding past turn 0 clamps to root).
   - Branch ledger integrity: verifying soft-deleted turns exist under `branch_id` and hash chain validates.
</action>
<verify>
pytest tests/test_timeline_rewind.py -v
</verify>
<done>
Conversational timeline rewind rolls back active dialogue, tool outputs, and execution states to any designated turn, soft-branching discarded turns into the ledger with full auditability and passing all verification tests.
</done>

<action>
1. Create `src/harness_core/cognition/title_synthesizer.py`:
   - Implement `TitleProvenance`: Enum `("DERIVED", "LLM", "USER")` enforcing strict hierarchy where `USER` overrides `LLM`, and `LLM` overrides `DERIVED`.
   - Implement `derive_instant_title(user_text: str, max_chars: int = 48) -> str`: Stage 1 instant title extracted from first non-empty line of opening prompt with punctuation trimming.
   - Implement `SessionTitleSynthesizer`:
     - Spawns background worker thread or `asyncio.Task` after Turn 1/2 of a session.
     - Calls configured model provider (preferring local Tier-1 model or fast cloud tier) with structured JSON prompt:
       `"Generate a 3 to 5 word title summarizing the user's objective. Output JSON: {\"title\": \"...\"}. Do not answer the query. Return title only."`
     - Validates candidate title against strict anti-chatter guards:
       - Word count ceiling: $\le 12$ words.
       - CJK character limit: $\le 20$ chars with sentence punctuation.
       - Answer-shaped heuristic rejection: rejects responses starting with "Yes", "Certainly", "Here is", or ending with full answer sentences.
       - Verbatim example echo guards.
     - On successful generation, updates `tasks.goal` in `LedgerStore` with `provenance="llm"` and triggers optional listener callback.
2. Enhance `LedgerStore` in `src/harness_core/storage/db.py`:
   - Implement `update_task_goal(task_id: str, new_goal: str, provenance: str = "llm") -> bool`:
     - Respects provenance hierarchy (never overwrites a user-explicit title).
     - Records a hash-chained `TASK_TITLE_UPDATED` event in `task_events`.
3. Integrate into `ReActLoop` (`src/harness_core/core/react_loop.py`) and `HexConsole` (`src/harness_core/client/tui.py`):
   - At start of turn 1, write instant derived title to `tasks.goal` if empty.
   - Upon turn 1 completion, schedule non-blocking `SessionTitleSynthesizer.synthesize_async()`.
   - Ensure the Start screen resume list (`SELECT task_id, goal, created_at FROM tasks`) retrieves the synthesized title seamlessly.
4. Export `SessionTitleSynthesizer` in `src/harness_core/cognition/__init__.py`.
5. Author comprehensive unit tests in `tests/test_title_synthesis.py`:
   - Instant derived title extraction.
   - Async LLM title upgrade with mock provider.
   - Provenance preservation (`user` overrides `llm`).
   - Anti-hallucination / answer-shaped output rejection guards.
   - Non-blocking execution behavior.
</action>
