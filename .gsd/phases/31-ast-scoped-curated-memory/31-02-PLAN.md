# Plan 31.02: JIT AST-Scoped Memory Injection into Tool Observations

<objective>
Implement Just-In-Time (JIT) AST-scoped memory injection that attaches architectural notes, gotchas, and failure post-mortems to AST symbols and their 1-hop callers/callees, dynamically injecting them into tool observation outputs (e.g. `read_file`) without busting the system prompt KV-cache prefix.

Purpose: Eliminate system prompt bloat while delivering surgical, symbol-specific code gotchas and 1-hop caller/callee invariants to the agent at the exact instant it inspects or edits target files.
Output: AST node memory store in `src/harness_core/memory.py`, JIT observation injection in `gateway.py` and `react_loop.py`, and test suite in `tests/test_ast_scoped_memory.py`.
</objective>

  <name>Task 1: Node-Bound AST Memory Model & Graphify 1-Hop Traversal</name>
  <files>src/harness_core/memory.py</files>
  <action>
    Enhance `src/harness_core/memory.py` with:
    1. `ASTNodeMemoryStore`:
       - Data model: `ASTNodeMemory` (id, symbol_name, rel_path, note, category: "gotcha" | "invariant" | "post_mortem", code_fingerprint: sha256, created_at, updated_at).
       - Persistence: stored in `.hex/memories/ast_memories.json` (or workspace SQLite ledger table `ast_node_memories`).
       - Methods: `record_node_memory(...)`, `get_node_memories(symbol_or_path)`, `list_all_node_memories()`.
       - Automatic code fingerprinting: compute SHA-256 of the symbol's enclosing file/definition at time of recording.
    2. Graphify 1-Hop Caller/Callee Resolution:
       - Implement `query_jit_memories_for_file(workspace_dir, rel_path, graphify_adapter) -> list[dict[str, Any]]`:
         a. Extract all AST symbols defined in `rel_path` from `graphify_adapter`.
         b. For each symbol, query 1-hop callers and 1-hop callees from `graphify_adapter`.
         c. Query `ASTNodeMemoryStore` and `GuardrailsManager` for notes matching `rel_path`, the defined symbols, or their 1-hop neighbors.
         d. Staleness check: compare stored code fingerprint against current file content; omit or flag stale entries if code mutated.
       - Format concise injection payload:
         ```markdown
         [AST Memory & Invariants for <path>]
         - Gotcha (<symbol>): <note> (SHA: <sha[:8]>)
         - 1-Hop Caller Warning (<caller_symbol> -> <symbol>): <note>
         - Guardrail: <relevant [AVOID] rule>
         ```
    AVOID: Loading entire file trees or deep multi-hop graph traversals that exceed token budgets; strictly limit to 1-hop callers/callees.
  </action>
  <verify>.venv/bin/pytest tests/test_ast_scoped_memory.py -k "test_ast_node_memory or test_1hop_resolution" -v</verify>
  <done>ASTNodeMemoryStore records and retrieves symbol-linked memories; query_jit_memories_for_file extracts 1-hop callers and callees with staleness validation.</done>
