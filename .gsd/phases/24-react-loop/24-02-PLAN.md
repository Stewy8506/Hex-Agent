# Plan 24-02: Orchestrator & TUI Integration with ReAct Loop

**Phase:** Phase 24 — Continuous Multi-Turn ReAct Tool Loop (Hermes Parity Pillar 1)  
**Task:** 24-02  
**Wave:** 2  
**Objective:** Wire `ReActLoop` into `HarnessOrchestrator` (`run_agent_loop`, `execute_task`) and `HexConsole` so users in the Cockpit TUI or CLI can run continuous multi-turn autonomous coding sessions with live tool streaming.

---

### Context & Requirements
- `HarnessOrchestrator`:
  - Add `run_agent_loop(task_id, goal, max_turns=30)` method that instantiates `ReActLoop` wired to the orchestrator's `router` and `gateway`.
  - Provide fallback when model has no active API key (deterministic mock tool planner).
- `HexConsole` in `src/harness_core/tui.py`:
  - Add `/react [on|off]` slash command to toggle autonomous multi-turn tool calling mode in chat.
  - When enabled, `handle_user_prompt` uses `run_agent_loop` and prints each tool call and result card interactively.
- CLI in `src/harness_core/cli.py`:
  - Add `--react` flag to `hex run` and `hex chat` to enable autonomous multi-turn ReAct mode.

---

### Proposed Implementation Tasks
1. Update `src/harness_core/orchestrator.py`:
   - Implement `run_agent_loop(goal, workspace_root=None, max_turns=30) -> dict[str, Any]`.
   - Record ReAct lifecycle events in `LedgerStore`.
2. Update `src/harness_core/tui.py`:
   - Register `/react` slash command in `HexConsole`.
   - Render progressive tool call badges and status indicators during ReAct loops.
3. Update `src/harness_core/cli.py`:
   - Register `--react` flag in argument parsers.
4. Expand `tests/test_react_loop.py`:
   - Integration tests covering `orchestrator.run_agent_loop`, `/react` TUI command, and CLI execution.
