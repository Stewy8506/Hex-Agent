# Plan 24-01: Continuous Multi-Turn ReAct Loop Engine Core

**Phase:** Phase 24 — Continuous Multi-Turn ReAct Tool Loop (Hermes Parity Pillar 1)  
**Task:** 24-01  
**Wave:** 1  
**Objective:** Author the standalone ReAct autonomous tool-calling engine in `src/harness_core/react_loop.py` that executes iterative turns, dispatches tool calls through `ToolGateway`, records steps, and terminates cleanly upon task resolution or turn limits.

---

### Context & Requirements
- In Hermes Agent (`run_agent.py`), the model executes up to 500 iterative turns of calling tools and receiving observations before returning a final answer.
- HEX requires `ReActLoop` in `src/harness_core/react_loop.py` with:
  1. `ReActConfig`: `max_turns` (default 30), `temperature`, `system_prompt`, `budget_tokens`.
  2. `ReActTurn`: Turn index, thought/reasoning, list of tool calls, tool results, execution latency.
  3. `ReActLoop`:
     - Accepts model caller (e.g., `router.generate` or cloud reasoner callable), `ToolGateway`, and `workspace_root`.
     - Detects structured tool calls from JSON objects or function call blocks.
     - Invokes `ToolGateway.tools[name].handler(workspace_root, arguments)`.
     - Appends observations in standard format back to messages.
     - Loops until no tool calls are emitted, `<finish>` is issued, or max turns reached.
     - Records sealed steps into ledger.

---

### Proposed Implementation Tasks
1. Create `src/harness_core/react_loop.py`:
   - Data structures `ReActConfig`, `ToolCallRequest`, `ToolCallResult`, `ReActTurn`, `ReActSessionResult`.
   - Engine `ReActLoop` with `run(initial_prompt, ...)` and async `run_async(...)`.
   - Safe parsing of tool call payloads across JSON schema and XML function tags.
2. Author comprehensive unit test suite in `tests/test_react_loop.py`:
   - Multi-turn tool execution (e.g., read file -> analyze -> write file -> finish).
   - Early termination on `<finish>` or final message without tool calls.
   - Max turn exhaustion handling.
   - Tool execution error handling (model receives error observation and can retry).
