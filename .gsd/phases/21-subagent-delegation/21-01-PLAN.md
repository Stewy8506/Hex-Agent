<task type="auto">
  <name>Implement SubagentManager & Role-Constrained Sandbox Engine</name>
  <files>src/harness_core/subagent.py</files>
  <action>
    Create `src/harness_core/subagent.py`:
    1. Define `SubagentRole` enum: `RESEARCHER`, `CODER`, `TESTER`, `REVIEWER`, `PLANNER`, `GENERAL`.
    2. Define role-based allowed tool mapping (`ROLE_ALLOWED_TOOLS`):
       - `RESEARCHER`: read-only investigation (`read_file`, `list_files`, `search_files`, `web_search`, `web_extract`, `query_graphify`, `lsp_diagnostics`, `lsp_definition`, `lsp_references`, `lsp_hover`).
       - `CODER`: implementation & repair (`read_file`, `list_files`, `search_files`, `write_file`, `patch`, `run_tests`, `lsp_diagnostics`, `lsp_definition`, `lsp_references`, `lsp_hover`).
       - `TESTER`: verification (`read_file`, `list_files`, `run_tests`, `lsp_diagnostics`).
       - `REVIEWER`: static analysis & blast radius (`read_file`, `list_files`, `search_files`, `query_graphify`, `lsp_diagnostics`, `lsp_definition`).
       - `PLANNER`: task breakdown (`read_file`, `list_files`, `search_files`, `todo`, `query_graphify`).
       - `GENERAL`: standard tools without `delegate` (prevents uncontrolled recursive spawning).
    3. Define `SubagentRecord` and `SubagentResult` dataclasses with `subagent_id`, `parent_task_id`, `role`, `status` (`RUNNING`, `COMPLETED`, `FAILED`, `TIMED_OUT`), `summary`, `artifacts`, `diff_summary`, and `started_at`/`ended_at`.
    4. Implement `SubagentManager`:
       - `__init__(ledger, cow, router, gateway, max_depth=2)`: binds persistence, snapshotting, and tool gateway.
       - `spawn_subagent(parent_task_id, goal, role, context, parent_ws, current_depth=0, budget=None, timeout=120.0, wait=True) -> SubagentResult | str`:
         - Enforces `current_depth < self.max_depth` (raises `MaxRecursionDepthExceededError`).
         - Creates isolated CoW branch workspace at `parent_ws / ".hex" / "subagents" / subagent_id`.
         - Applies role-based tool filter.
         - Synchronously executes child reasoning loop or schedules asynchronous worker thread.
         - Returns structured `SubagentResult` or `subagent_id`.
       - `get_subagent_status(subagent_id: str) -> dict[str, Any]`
       - `wait_subagent(subagent_id: str, timeout: float = 60.0) -> SubagentResult`
       - `list_active_subagents() -> list[dict[str, Any]]`
  </action>
  <verify>

  </verify>
  <done>
    `SubagentManager` successfully defined with role-based tool gating, depth bounds, and CoW workspace branching.
  </done>
