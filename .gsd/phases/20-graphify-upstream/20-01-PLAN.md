<task type="auto">
  <name>Implement GraphifyUpstreamRunner, ingest_upstream_graph, and CLI Commands</name>
  <files>src/harness_core/graphify.py, src/harness_core/cli.py</files>
  <action>
    1. In `src/harness_core/graphify.py`:
       - Implement `GraphifyUpstreamRunner`:
         - Method `is_cli_available() -> bool`: checks if `shutil.which("graphify")` is present or `vendor/graphify` directory exists on disk.
         - Method `run_command(cmd: str, args: list[str] | None = None, cwd: Path | None = None, timeout: float = 60.0) -> tuple[int, str, str]`:
           - If `graphify` executable is in PATH, invokes `["graphify", cmd, *args]` via `subprocess.run`.
           - Else if `vendor/graphify` exists, runs `[sys.executable, "-m", "graphify", cmd, *args]` with `PYTHONPATH` prepended with `vendor/graphify`.
           - Handles timeouts returning `(-1, "", "Timeout expired")`.
         - Method `run_update(workspace_root: Path, force: bool = True, no_cluster: bool = True) -> tuple[bool, Path]`:
           - Attempts CLI/subprocess update. If output file `workspace_root / "graphify-out" / "graph.json"` is created, returns `(True, path)`.
           - Otherwise executes in-process fallback using `from graphify.watch import _rebuild_code`:
             `_rebuild_code(watch_path=workspace_root, force=force, no_cluster=no_cluster, acquire_lock=False)`.
           - Returns `(True, out_path)` if graph file exists, else `(False, out_path)`.
         - Method `run_extract(workspace_root: Path, force: bool = True) -> tuple[bool, Path]`:
           - Invokes extraction via CLI (`extract` command) or in-process `_rebuild_code(..., no_cluster=True)`.
       - In `ActiveGraphifyAdapter`:
         - Implement `ingest_upstream_graph(path: Path | str | None = None) -> dict[str, Any]`:
           - Candidate path discovery if `path` is None: checks `workspace_root / "graphify-out" / "graph.json"` then `workspace_root / ".hex" / "graph.json"`.
           - If no file exists, cleanly returns `{"ingested": False, "node_count": 0, "edge_count": 0, "path": None}` without raising (preserving fast 0ms native Python AST fallback).
           - When valid JSON is loaded:
             - Initializes `self.graph = nx.DiGraph()` if not present.
             - Ingests `nodes`: extracts `id`, `label`, `kind`/`node_type`, `source_file`, `lineno`, `end_lineno`.
             - Reconciles file nodes and code symbols into `self.symbols_by_file`, `self.symbols_by_name`, `self.file_of_qualified`, creating `SymbolDef` instances.
             - Ingests `links` / `edges`: extracts `source`, `target`, `relation`, `confidence` (`EXTRACTED` or `INFERRED`), `source_file`.
             - Preserves and adds all nodes and edges to `self.graph`.
             - Reconciles `self.callers_of` for reverse dependency traversal.
             - Returns `{"ingested": True, "path": str(graph_path), "node_count": len(self.graph.nodes), "edge_count": len(self.graph.edges)}`.
    2. In `src/harness_core/cli.py`:
       - Register `hex graphify` subcommand parser with subcommands:
         - `status`: prints CLI discovery status, active graph path, node and edge counts.
         - `update`: runs `GraphifyUpstreamRunner().run_update()` on workspace.
         - `ingest`: runs `ActiveGraphifyAdapter.ingest_upstream_graph()` and reports ingested counts.
         - `god-nodes`: runs `ActiveGraphifyAdapter.analyze_architecture()` and displays core abstractions.
         - `affected`: queries affected nodes for a specified symbol or file.
         - `tree`: generates interactive architecture HTML tree visualization via `export_interactive_html()`.
    AVOID: Crashing if `vendor/graphify` or optional dependencies are absent; always maintain zero-dependency native Python AST fallback.
  </action>
