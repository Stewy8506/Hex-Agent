       - Expand `SUPPORTED_CODE_EXTENSIONS` to include Java (`.java`) and C/C++ (`.c`, `.cpp`, `.cc`, `.cxx`, `.h`, `.hpp`).
       - Update `ActiveGraphifyAdapter._is_test_file(rel_path: str) -> bool`:
         - Detect Python tests: `test_*.py`, `*_test.py`
         - Detect TypeScript / JavaScript tests: `*.test.ts`, `*.test.tsx`, `*.spec.ts`, `*.spec.tsx`, `*.test.js`
         - Detect Go tests: `*_test.go`
         - Detect Rust tests: `test_*.rs`, `*_test.rs`, paths under `tests/*.rs`
         - Detect Java tests: `*Test.java`, `*Tests.java`, `*TestCase.java`, `Test*.java`
         - Detect C/C++ tests: `test_*.cpp`, `test_*.cc`, `*_test.cpp`, `*_unittest.cc`
         - Recognize common test directory paths: `tests/`, `__tests__/`, `spec/`.
       - In `ActiveGraphifyAdapter.compute_blast_radius`:
         - Support polyglot file modifications: for non-Python modified files, check if the file or its defined symbols exist in `self.graph` or `self.symbols_by_file`.
         - Traverse 1-hop and 2-hop dependents through upstream `graphify.affected` (if available) or `self.graph.predecessors` / `self.callers_of`.
         - Map affected node IDs to their source files across all supported languages.
         - Filter and pin every affected test file into `impacted_tests`.
         - Generate descriptive warning messages detailing polyglot modified files, 1-hop/2-hop dependents, and impacted tests.
    2. In `src/harness_core/gateway.py`:
       - Define helper class `ActiveBlastRadiusInterceptor` wrapping `ActiveGraphifyAdapter.compute_blast_radius`.
       - In `ToolGateway.invoke`:
         - Update the R2 file modification hook for `write_file`:
           Replace the Python-only check `if rel_p.endswith(".py"):` with checking if the file has a supported code extension (`Path(rel_p).suffix.lower() in SUPPORTED_CODE_EXTENSIONS`).
         - Ensure `ast_blast_radius` payload is attached to `sanitized_result`, and when `br.impacted_tests` or `br.hop1_dependents` are found, append them to `self.ledger.append_blast_radius_checks(task_id, br.impacted_tests, br.warning_message)`.
    AVOID: Breaking existing native Python AST blast radius; ensure zero-regression compatibility for pure Python workspaces and 0ms memoization.
