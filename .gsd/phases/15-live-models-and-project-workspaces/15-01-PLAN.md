# Plan 15.01: Live Dynamic Model Discovery Engine

<objective>
Invert the onboarding and model configuration flow to authenticate the chosen provider FIRST, immediately query the live provider API for available models, present the real available models in `TerminalUISelector`, and provide graceful offline fallback with clear badging.

Purpose: Eliminate stale, fictitious, or inaccessible model IDs by dynamically querying active provider capabilities at runtime while keeping offline workflows fully functional.
Output: Dynamic model discovery across Antigravity, Anthropic, OpenAI, Gemini, and Ollama with offline fallbacks in `antigravity_provider.py`, `cloud_provider.py`, `onboard.py`, and `tui.py`.
</objective>

  <action>
    1. In `src/harness_core/providers/antigravity_provider.py`:
       - Add `fetch_available_models(access_token: str | None = None, timeout: float = 3.0) -> list[tuple[str, str]]` to `AntigravityModelProvider` and `AntigravityOAuthManager`.
       - Query `POST https://cloudaicompanion.googleapis.com/v1internal:fetchAvailableModels` (or `self.base_url`) using the resolved access token and companion project ID.
       - Extract available models from response `models` map, formatting label with `displayName` and remaining quota percentage if present.
       - If call fails (network error, timeout, HTTP 401/403/404), return curated fallback:
         - `("gemini-2.5-pro", "gemini-2.5-pro [offline fallback]")`
         - `("gemini-2.5-flash", "gemini-2.5-flash [offline fallback]")`
         - `("claude-3-5-sonnet", "claude-3-5-sonnet [offline fallback]")`

    2. In `src/harness_core/providers/cloud_provider.py`:
       - Implement `fetch_available_models(provider_type: CloudProviderType | str, api_key: str | None = None, timeout: float = 3.0) -> list[tuple[str, str]]`:
         * **Anthropic**: `GET https://api.anthropic.com/v1/models` with headers `{"x-api-key": api_key, "anthropic-version": "2023-06-01"}`. Parse `data` array, sort by `display_name` / `id`. Curated fallback: `claude-3-7-sonnet`, `claude-3-5-sonnet`, `claude-3-5-haiku`.
         * **OpenAI**: `GET https://api.openai.com/v1/models` with header `{"Authorization": f"Bearer {api_key}"}`. Parse `data` array, filtering for models matching `gpt-4o`, `gpt-4.5`, `o1`, `o3-mini`, `gpt-4-turbo`. Curated fallback: `gpt-4o`, `o1`, `o3-mini`, `gpt-4o-mini`.
         * **Google Gemini**: `GET https://generativelanguage.googleapis.com/v1beta/models?key={api_key}`. Filter models where `supportedGenerationMethods` contains `generateContent`. Strip prefix `models/`. Curated fallback: `gemini-2.5-pro`, `gemini-2.5-flash`, `gemini-2.0-flash`.
         * **Ollama / Local**: `GET http://localhost:11434/api/tags`. Parse `models` list, extract `name`. Curated fallback: `qwen2.5-coder:7b`, `llama3.3:70b`, `deepseek-r1:8b`, `codellama:13b`.
       - Ensure all HTTP requests use standard library `urllib.request` with strict `timeout=3.0` and catch `urllib.error.URLError`, `urllib.error.HTTPError`, `TimeoutError`, and `Exception`.
       - On any failure or empty list, append ` [offline fallback]` to each label in the curated fallback list.

    AVOID: Hardcoding blocking network calls without timeout. Always set `timeout=3.0` so offline terminals never freeze.
    AVOID: Crashing if API response schema is missing optional fields. Safely use `.get()`.
  </action>

  </verify>
  <done>
    `fetch_available_models` returns formatted tuples `(model_id, label)` across all providers and returns `[offline fallback]` tuples when network or credentials fail.
  </done>
