- **3.2 B20/B25/B26** `[DONE]` — Approval prompts remain pending until a matching `applied` acknowledgement; transport failures, negative/mismatched acknowledgements and missing connections preserve an actionable retry state. Both live ConPTY regressions pass: native input plus gated approval error/negative-ACK/retry/allow/scope/deny, pending-decision deduplication, tiny-screen allow blocking, Unicode/multiline review, modal stacking, canonical uppercase model confirmation, cancellation failure/terminal confirmation and clean exit. Old-behavior probes produce real assertion failures for B20/B25/B26; the uppercase-command and cancellation-hint regressions also fail before their corrections.
